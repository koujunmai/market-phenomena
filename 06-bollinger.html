ボリンジャーバンドの±2σは効くのか──正反対の2つの教えが、どちらも本当だった

0. この記事の立ち位置

ここまでの5回で、移動平均のクロス、パーフェクトオーダー、押し目買い、RSI、MACD、 そして高値・安値の切り上がりを調べてきました。どれも「買って放置」には届きませんでした。

今回のボリンジャーバンドは、これまでと問いの立て方が違います。

成績を調べる前に、ひとつ気づいたことがあるからです。 ボリンジャーバンドについては、正反対の2つの教えが、どちらも堂々と語られています。

−2σ は、価格の95%が収まる下限。そこまで下げたのは売られすぎ。買い。 中央線（20日移動平均）まで戻ったら利確する。

−2σ で買うのは落ちるナイフを掴む行為。バンドは抜けるためにある。 +2σ を上抜けたら、そこからが本番。買い。

同じ指標の、同じ線を見て、一方は「反発する」と言い、他方は「抜ける」と言っています。 しかも両方に支持者がいて、両方が何年も生き残っています。

普通に考えれば、どちらかが間違っているはずです。 そこで今回は、両方を同じ土俵に並べて測りました。

先に、今回の見どころを言っておきます。

どちらも間違っていませんでした。両方とも、実際に起きていました。 そして今回は、この連載で「買って放置」に最も近づいた回でもあります。 勝率77.7%、PF1.78。ランダムに買った場合も明確に上回りました。 それでも、届きませんでした。

使う数字の土台は前回までと同じです（詳しくは第0回・第1回で扱っています）。

  • 対象は 1306（TOPIX連動ETF） と、国内の中〜大型株 552銘柄。期間は 2005-11 〜 2026-07。
  • 個別552銘柄には生存者バイアスがあるので、絶対的な成績は出さず、比べ方（相対比較）だけに使います。 主な結論は、バイアスのない指数（1306）で出します。
  • 比較の基準は 「買って放置」。最初に一度だけ買って、あとは何もせず持ち続けるだけ。 チャートも見ない。売買の判断を一切しない。毎月の積立とは別物です（積立は買う時期が分かれるので、話が変わります）。

条件は計算を始める前に文書に固定し、記録として残してあります。 結果を見てから条件を変えていない、ということです。

1. 「ボリンジャーバンドの±2σ」を、計算できる形にする

ボリンジャーバンドは3本の線でできています。

  • 中央線: 直近20日の終値の平均
  • 上バンド（+2σ）: 中央線 ＋ 直近20日のばらつき（標準偏差）の2倍
  • 下バンド（−2σ）: 中央線 − 同じもの

値動きが荒れればバンドは広がり、静かになれば狭まります。 「95%が収まる」と言われるのは、この2σという幅の由来が正規分布の性質だからです。

買い方は、正反対の2つを含めて3通り用意しました。

買うとき 売るとき
A 逆張り 終値が −2σ を下回った日 中央線まで戻ったら
B 順張り 終値が +2σ を上抜けた日 中央線を割ったら
C 逆張り・欲張り A と同じ（−2σ を下回った日） +2σ に届くまで持つ

A と B が、冒頭の正反対の2つです。 C は「中央線で利確するのは早すぎる、バンドの反対側まで取れ」という、これもよく聞く言い方です。

いずれも、シグナルが出た翌営業日の始値で売買しています（当日の終値では買えないため）。 売買コストは往復5bp（0.05%）を差し引いています。

なお「バンドウォーク」（+2σに張り付いている間は乗り続ける）と 「スクイーズ」（バンドが狭まった後に大相場が来る）は、今回は扱っていません。 別の主張なので、別の回で扱います。

2. まず、単体の成績を見てみる──今回は、かなり良い

指数（1306）で、20年ぶんの成績です。

回数 勝率 1回あたり平均 PF 最大の下げ 市場にいた時間
A 逆張り 94回 77.7% +0.92% 1.78 −36.5% 19.3%
B 順張り 87回 34.5% +0.48% 1.42 −22.3% 31.3%
C 逆張り・欲張り 56回 78.6% +1.73% 1.95 −45.7% 47.6%

PF（プロフィットファクター）は「勝ちの合計 ÷ 負けの合計」で、1を超えていれば勝ち越しです。

正直に書きますが、この数字は良いです。 逆張りは10回のうち8回近く勝っていて、勝ち負けの金額比も 1.78。 ここまでの5回で、これほど見栄えのする数字は出ていません。

しかも、これまでなら効いた「言い訳」が、今回は通用しませんでした。

💬 読者の疑問 「たまたま大当たりが数回あっただけでは？」

それは今回、当てはまりませんでした。 いちばん儲かった3回を丸ごと除いても、A の PF は 1.59、C は 1.60 で、1を超えたままです。 （前回までの5つの現象は、この操作をすると全部 PF が1を割りました。 「数回の大当たりで成り立っていた」と説明できたのです。今回はできません。）

💬 読者の疑問 「同じ回数だけ、ランダムに買ったらどうなりますか？」

これも今回は違いました。 同じ回数・同じ保有期間で、日付だけをでたらめに選ぶ試行を1,000回まわしました。 A の成績は、そのランダム分布の上位5%以内（95.3パーセンタイル）に入ります。 個別552銘柄では、なんと1,000回中いちばん上（100パーセンタイル）でした。

これまでの5回は、指数でパーセンタイル24〜59、個別に至っては0.0〜4.2という 「ランダムに買ったほうがマシ」という水準でした。今回は明確に違います。

つまり、−2σ で買うという判断そのものには、情報があります。 でたらめに買うより、はっきり良い。ここは否定しません。

3. 「買って放置」と比べる

ここが山場です。

手法に意味があるかどうかは、勝ったかどうかでは決まりません。 何もしなかった人に勝てたかどうかで決まります。

買う時期によって結果は変わるので、開始時期を1年ずつずらして22通り計算しました。

手法が「買って放置」を上回った開始時期は、A・B・C とも 0 通りでした（0/22）。

100万円を2005年11月に投じて、2026年7月まで置いた場合です。

20年後の資産
買って放置 275万円
A 逆張り 212万円
B 順張り 141万円
C 逆張り・欲張り 225万円

22通りの開始時期の中央値で見ると、こうなります。

中央値
買って放置 259万円
A 逆張り 204万円
C 逆張り・欲張り 217万円
B 順張り 98万円

A と C は、お金は増えています。損はしていません。 100万円が204万円、217万円になっている。ただ、何もしなかった人は259万円になっていた。 この差は「損失」ではなく「取りこぼし」です。

B（順張り）だけは事情が違います。 中央値98万円は、元本を割っています。 1回あたりの平均はプラス（+0.48%）なのに、積み上げると減る。 勝ったり負けたりを繰り返すと、掛け算の性質で目減りしていくためです。

💬 読者の疑問 「買って放置は暴落を丸ごと食らうはず。逃げられるだけでも価値があるのでは」

その指摘は正しく、数字にも出ています。 買って放置の最大の下げは −61.3%。それに対して A は −36.5%、B は −22.3%。 下げは実際に浅いです。これは手法の実在する長所なので、隠さず書きます。

ただ、値段は見ておいてください。20年後に残ったのは A が212万円、買って放置が275万円。 下げの浅さを買うために、63万円を渡しているという形です。

そしてもう一点。この下げ耐性は「市場にいない時間が長い」ことから来ています。 A が市場にいたのは全期間の 19.3% だけ。下げに居ないということは、上げにも居ないということです。

4. 出てくる疑問を、先に一緒に潰しておく

「20日・2σ という設定が悪い。パラメータを変えれば」

期間を10・20・25・50日、σ幅を1.0・1.5・2.0・2.5・3.0倍で、 出口や手数料も含めて840通りまで振りました。

  • 買って放置に過半の開始時期で勝った設定は 8通り（0.95%）
  • 1つでも勝ちがあった設定は 76通り（9.0%）

ここは正確に書きます。「全部の設定で負けました」は事実に反します。 勝ちのある設定は、確かに存在しました。

ただし、勝った8通りは全部が同じ形をしています。 バンドを浅く（10日・1σ）して、出口を「20営業日で機械的に手仕舞い」にしたもの。 このとき市場にいた時間は 45〜65% で、主結果の19.3%とはまるで違います。

つまりバンドの判断が効いたのではなく、市場にいる時間を「買って放置」に近づけただけです。 しかもその設定でさえ、勝った開始時期は最大でも14/22（手数料込み）で、 上回った回数は多いのに、増えた金額の中央値は買って放置より低い（150.6万 vs 159.1万）。 多くの時期で小さく勝ち、少数の時期で大きく負けている、ということです。

「終値ではなく、ザラ場でタッチしたら買うのが本来のやり方だ」

日中の安値・高値でタッチを判定する版も計算しました。 シグナルは増えますが、3通りとも成績はやや落ち、0/22 は変わりません。

「シグナルが出ていない間は現金だろう。市場にいる時間が違う」

正当な指摘です。なので、シグナルが出ていない期間の資金を1306に置いた場合も計算しました。 「手法＋余りは指数」対「全部指数」なら、市場にいる時間の差が消えます。

結果は A 153.3% / B 152.4% / C 155.5% 対 買って放置 159.1%。やはり 0/22 です。 これまででいちばん近いところまで来ましたが、届きませんでした。

「手数料が厳しすぎるのでは」「配当を入れれば放置が有利なだけでは」

手数料をゼロにしても 0/22 です。 配当については、本稿は分配金を含めていないので買って放置を過小評価しています。 仮に年1.5%・2.0%を戻して計算し直しても、やはり 0/22 でした。

「個別株ならどうなんですか」

552銘柄でも A・B・C とも 0/17 です。 ただし個別のデータには生存者バイアス（今も残っている会社しか入っていない）があるので、 絶対的な成績としては読めません。向きが一致した、という以上のことは言えません。

5. なぜ勝てないのか──平時に積み上げ、暴落で吐き出す

ここまでの5回では、負ける理由の多くが「市場にいない時間が長いから」で説明できました。 今回は、それだけでは足りません。市場にいる時間を揃えても届かなかったからです。

年別の成績を見ると、理由がはっきりします。

A（逆張り）は 21年のうち17年がプラスです。マイナスはたった4年。 毎年こつこつ積み上がっているように見えます。

ところが——
2008年の1年 −27%
いちばん大きな負け 2008-09-08 に買い、10-31 に手仕舞い。−26.1%（36営業日）
いちばん大きな勝ち 2015-07-09 に買い、07-17 に手仕舞い。+7.5%（6営業日）

勝ちは最大でも +7.5%、負けは −26.1%。

これが勝率77.7%の正体です。 −2σ で買って中央線まで戻れば利確、というルールは、利益の上限が構造的に決まっています （中央線までの距離しか取れない）。一方で下げが止まらないときは、 中央線が価格を追いかけて下がり続けるので、戻ってこないまま含み損が膨らみます。

小さく何度も勝ち、数年に一度、それまでの積み上げをまとめて返す。 PF1.78・勝率77.7%と、買って放置に0/22は、この形で同居しています。

C（欲張り版）はもっと極端で、2008-09-08 に買って2009-03-24 まで129営業日持ち、−31.5% でした。 「反対側のバンドまで待つ」というルールが、そのまま「戻るまで待つ」になってしまったわけです。

6. 正反対の2つの教えは、どちらも本当だった

ここが今回の核心です。

冒頭の2つ——「−2σ は反発する」と「−2σ は落ちるナイフ」——のどちらが正しいのか。 指数が −2σ を下抜けた 141回すべてについて、その後に何が起きたかを数えました。

−2σ を下抜けた後 中央線まで戻った さらに沈んだ
5営業日以内 20.6% 65.2%
10営業日以内 55.3% 70.2%
20営業日以内 86.5% 77.3%

逆張り派は正しい。 20営業日待てば、86.5%は中央線まで戻っています。 「−2σ まで下げたら、いずれ戻る」——これは本当です。

順張り派も正しい。 ただし5営業日で見ると、65.2%はさらに下に沈んでいます。 「落ちるナイフを掴むな」——これも本当です。

しかも、先に起きるのは「沈むほう」です。 20営業日以内に「戻り」が「さらなる下落」より先に来たのは、29.8%しかありません。 つまり10回のうち7回は、まず痛い目に遭ってから、そのあと戻る。

（+2σ を上抜けた後も対称に測りました。5営業日以内に83.3%がさらに上げ、 20営業日以内には91.7%がさらに上げる。順張り派の言い分は、上側ではもっと強く出ます。）

💬 読者の疑問 「両方本当なら、どちらに従えばいいんですか？」

それが今回いちばんお伝えしたいことです。

正反対の主張が両方とも生き残っているのは、どちらかが嘘をついているからではありません。 両方とも、実際に起きているからです。

逆張りで痛い目に遭った人は「やっぱりナイフは掴むものじゃない」と学びます。 そのまま持って戻ってきた人は「やっぱり −2σ は買いだ」と学びます。 同じ141回の出来事から、正反対の教訓が両方とも、正しく抽出できてしまう。

そして、どちらの流儀で20年やっても——買って放置には届きませんでした（どちらも0/22）。

もうひとつ、時期による入れ替わりも起きています。

前半（2005〜2016） 後半（2016〜2026）
A 逆張り PF 1.19 PF 4.06
B 順張り PF 2.31 PF 0.91

前半は順張りが強く、後半は逆張りが強い。（B の直近24ヶ月は PF 0.18 です。） どちらが効くかは時期によって入れ替わり、そしてその入れ替わりを事前に知る方法はありません。

7. 「でも、効いた時は本当にあったよね」

あります。この連載でいちばんはっきり、あります。

  • 勝率 77.7%
  • PF 1.78（大当たりを3つ除いても 1.59）
  • ランダムに買うより明確に上（上位5%以内）
  • 21年のうち17年がプラス
  • 下げは買って放置より25ポイント浅い

これは「効いているように見えた」ではなく、実際に効いています。 −2σ で買うという判断には情報があり、それは測定できました。

問題は、そこではありません。

2008年が来ることを、事前に知る方法がないということです。 2008-09-08 に −2σ で買った人は、それまでと同じルールに従っただけです。 ルールを破ったわけでも、下手だったわけでもない。同じことをして、−26.1% を引きました。

「見分けられない」は、想像ではなく実測です

「じゃあ、効く時だけを選べばいい」——当然そう思います。私もそう思って、何度も試しました。

  • 相場のレジーム（強気/弱気）を事前に判定する試み → 6回やって全部だめ
  • VIX（恐怖指数）が高い時だけ逆張りする → だめ
  • 決算集中期・SQ週・権利落ち週で条件を分ける → だめ
  • 月末・月初などカレンダーで条件を分ける → だめ

これは「見分けられないと思います」という感想ではありません。 見分けようとして、これだけ失敗した記録です。

正直に書いておくこと

  • 今回、840通りのうち76通り（9.0%）には勝ちがありました。「全部負けた」ではありません。
  • ただしその上位は、バンドの判断ではなく市場にいる時間で説明がつく設定でした。
  • 個別552銘柄の数字は生存者バイアスのため、絶対的な成績としては使えません。
  • 下げの浅さ（−36.5% 対 −61.3%）は、実在する長所です。

8. まとめ──「両方本当」が意味すること

ボリンジャーバンドの±2σについて、正反対の2つの教えを同じ土俵で20年ぶん測りました。

どちらも本当でした。 −2σ の後、20営業日以内に86.5%は中央線まで戻る（逆張り派が正しい）。 ただし5営業日以内に65.2%はさらに沈む。先に来るのは沈むほうです（順張り派も正しい）。

そして逆張りには、実際に情報がありました。 勝率77.7%、PF1.78、ランダムより明確に上、大当たりを除いても1.59。 この連載で、ここまでの数字が出たのは初めてです。

それでも、買って放置には届きませんでした。 22通りの開始時期すべてで下回り（0/22）、手数料ゼロでも、 余った資金を指数に置いても、配当を戻しても、結果は同じでした。

負けの正体は損失ではありません。100万円は204万円に増えています（中央値）。 ただ、何もしなかった人は259万円になっていた。その差55万円は「取りこぼし」です。 （順張りだけは中央値98万円で、こちらは実際に元本を割っています。）

そして今回いちばん重要なのは、たぶんこれです。

正反対の教えが両方とも生き残っているのは、どちらも実際に起きているからでした。 だから両方に支持者がいて、両方に成功体験があって、両方が20年間語り継がれてきた。 どちらを選んでも、それぞれの流儀の中では「効いた記憶」が正しく積み上がります。

効く時は実在します。しかも今回は、これまででいちばんはっきり実在しました。 ただ、それが効く時かどうかを事前に見分ける手段が、やはり見つかりませんでした。

見分けられないなら、手元に残るのは全部の平均だけです。 そしてその平均は、何もしなかった人に届きませんでした。

次回予告: 一目均衡表の「三役好転」を調べます。 3つの条件が同時に揃う、いちばん信頼できる買いシグナルと言われるものです。 ただ、その「3つ」が本当に3つなのかを数えてみると、少し違う景色が見えてきます。

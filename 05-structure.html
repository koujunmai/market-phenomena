「高値切り上げ・安値切り上げ」は効くのか──後から引ける線は、その時には引けない

0. この記事の立ち位置

ここまでの4回で、移動平均のクロス、パーフェクトオーダー、押し目買い、RSI、MACD を調べてきました。 どれも「買って放置」に届きませんでした。

そこまで書いたとき、次の疑問が浮かびます。

それは全部インジケーターの話だから。 移動平均もRSIもMACDも、結局は過去の価格を加工した数字にすぎない。 加工すれば必ず遅れる。価格そのものを見ればいい。 高値が切り上がって、安値も切り上がっている。それが上昇トレンド。 指標なんて要らないはず。

これは筋の通った疑問です。しかも、これまでの4回への反論としていちばん強い形をしています。 「あなたが調べたのは全部インジケーターでしょう」と言われれば、そのとおりだからです。

そこで今回は、指標をひとつも使わない現象を調べました。 使うのは高値と安値だけ。世に言う「マーケットストラクチャ」「HH/HL」「プライスアクション」です。

先に、今回の見どころだけ言っておきます。

結果そのものは、これまでと同じでした（0/22）。 ただし今回は、これまでになかった落とし穴が見つかりました。 「高値が切り上がった」と分かるのは、その高値をつけた日ではありません。数日あとです。 そして──その遅れをなくしてあげても、結果は変わりませんでした。

  • 比較の基準は 「買って放置」。最初に一度だけ買って、あとは何もせず持ち続けるだけ。 チャートも見ないし、売買の判断もしません。積立（毎月コツコツ買う）とは別物です。

1. 「高値切り上げ・安値切り上げ」を、計算できる形にする

まず、この現象はそのままでは計算できません。ここが今回いちばん難しいところでした。

「高値が切り上がっている」と言うとき、その「高値」とは何でしょうか。 チャートを見れば、山の頂点は目で分かります。けれど目で分かるということは、 言葉になっていないということでもあります。言葉にしないと、計算もできません。

そこで、こう決めました。

ある日の高値が、その日の前後3営業日（合計7営業日）の中でいちばん高ければ、その日を「高値」とする。 安値も同じで、前後3営業日の中でいちばん安ければ「安値」とする。

これは「フラクタル」「スイングポイント」と呼ばれる、ごく一般的な決め方です。 そして上昇トレンドを、こう定義しました。

直近の「高値」が前の「高値」より高く、かつ直近の「安値」が前の「安値」より高い状態。

ここに、この現象だけの落とし穴があります

もう一度、高値の定義を読んでください。「前後3営業日の中でいちばん高い」。

"後"の3営業日が過ぎるまで、それが高値かどうかは分からないのです。

チャートを開けば、山の頂点には最初からそこに印がついているように見えます。 けれどそれは、もう右側が描かれ終わったチャートを見ているからです。 リアルタイムでは、右側はまだありません。

上の図の塗りつぶした三角が、後からチャートを見て引いた高値・安値です。 中抜きの三角が、それが「高値だった」と実際に確定する日。4営業日ずれています。

下の段を見てください。 灰色が「後から見れば上昇トレンドだった期間」、赤が「その時点で上昇トレンドだと分かっていた期間」。 赤はいつも、灰色より遅れて始まります。

この遅れを全期間で数えると、こうなります。

「後から見れば上昇トレンドだったが、その時点ではまだ分からなかった」日は、20年で478日。 全体の 9.5%、およそ2年ぶんです。

この記事は、最終的にこの「遅れ」の話に戻ってきます。

買い方は3通り用意しました

「マーケットストラクチャ」と呼ばれるものには、いくつかの言い方があります。全部やりました。

買い方 誰が言う形か
A 構造で乗る 高値と安値がそろって切り上がったら、その翌朝に買う 「上昇トレンドの間は持つ」という、いちばん素直な形
B 直近高値の上抜けで買う 終値が直近の高値を上に抜けたら、その翌朝に買う BOS（Break of Structure）。「高値を更新したらトレンド継続が確認できた」
C 安値割れで早く降りる 買い方はAと同じ。ただし直近の安値を割ったら、すぐ降りる CHOCH（Change of Character）。「安値を割ったらもう終わり」

A と B は入口だけが違い、A と C は出口だけが違います。 一度に一つずつしか変えていないので、 「入口が悪かったのか」「出口が悪かったのか」を切り分けて読めます。

前後何本で高値を判定するかも、2本・3本・5本・8本・10本・13本の6通りを掃引しました。 「直近2つが切り上がればトレンド」なのか「直近3つが単調に切り上がって初めてトレンド」なのかも、両方計算しています。

全部で 12通り × 3つの形 × 出口7通り × 手数料5水準 = 1,260通りです。

空売り（下降トレンドで売り建てる）は今回扱っていません。これは正直に、検証していない範囲として書いておきます。

3. 「買って放置」と比べる

これまでと同じ土俵です。開始した年を1年ずつずらして 22通り、 それぞれ「1306で売買した場合」と「1306を買って放置した場合」の、どちらが期末に多く残ったかを数えます。

B 直近高値の上抜けで買う −6% +159.1% 0 / 22
C 安値割れで早く降りる +24% +159.1% 0 / 22

22通りのどこから始めても、一度も上回りませんでした。

ここで、手法の実在する利点を先に書いておきます。

買って放置 A B C
いちばん深く沈んだ時 −61.3% −38.4% −35.2% −35.0%

💬 読者の疑問 「−61% と −38% なら、かなり大きな違いに見えます。 多少リターンが劣っても、沈まないほうを選びたいのですが」

その選び方は合理的です。否定しません。 ただ、値段は見ておいてください。20年後に手元に残ったのは A が130万円、買って放置が275万円。 下げの浅さを買うために、145万円を渡しているという形になります。

そしてもう一点。この下げ耐性は「市場にいない時間が多い」ことから来ています。 下げに居ないということは、上げにも居ないということです。 仕組みが同じなので、片方だけを取り出すことはできません。

そして、上段の図をもう一度見てください。

2020年ごろまで、Aの線（赤）は買って放置より上にあります。 日数で数えると、Aは20年のうち 2,419日（48%） で買って放置を上回っていました。 最後に上回っていたのは 2020年11月4日です。

手法に意味があるかどうかは、「勝ったかどうか」では決まりません。 何もしない人に勝てたかどうかで決まります。 PF が 1.25 でも、買って放置した人に届いていないなら、 その手法がやったことは「手間をかけて成績を下げた」ということです。

第4回でも同じことが起きました。手法が置いていかれるのは、いつも最後にまとめてです。 2021年以降の上げ相場で、市場にいなかった時間のぶんだけ一気に離されます。 それまでは、ずっと勝っているように見えます。

5. なぜ勝てないのか──やはり「市場にいなかった時間」

横軸が「その手法が実際に株を持っていた時間の割合」、縦軸が「手元に残ったリターン」です。 右上の星が買って放置（ずっと持っている＝100%）。

これまで5回で調べてきた現象が、全部その左下に並びます。

今回の市場滞在率は A 34.1% / B 27.6% / C 41.6%。 20年のうち3分の2は、現金で待っていたことになります。その間に市場が上げても、その上げは手元に入りません。

数字でも確認できます。貢献の大きかった上位3回の取引を除くと、 PF 1.25 だった A は 0.84、B は 0.73、C は 0.63 まで落ちて1を割り込みます。 20年ぶんの見かけの成績は、数回の大当たりに支えられていました。

年別に見ても、A は21年のうち 9年がマイナス、B は 14年、C は 13年がマイナスです。

6. 「後から見れば分かるじゃないか」を、実際にやってみる

ここからが、今回いちばん書きたかったところです。

§1 で見たとおり、この現象には確定の遅れがあります。 高値をつけた日には、それが高値だと分からない。数日待って初めて分かる。 20年のうち478日（9.5%）は、「後から見れば上昇トレンドなのに、その時点では分からない」状態でした。

では、この遅れが敗因なのでしょうか。

たとえば今回いちばん大きく勝った取引は、2012年12月5日の寄り付きで買ったものです。 そこから71営業日持って +34.0%。アベノミクス相場の入り口です。

けれど、その日の前を追うとこうなっています。

  • 11月28日：この日の安値が、あとから「安値」になる
  • 12月4日：その安値がようやく確定し、「高値も安値も切り上がった＝上昇トレンド」と判定される
  • 12月5日：ルールどおり、翌朝の寄り付きで買う

実際の安値から、5営業日あとに買っています。 ちなみに第4回の MACD は、同じ相場を 11月20日に買っていました。10営業日早い。

だとすれば、「遅れさえなければ勝てたのでは」と思うのが自然です。 そこで、遅れをなくしてあげました。

高値・安値を、それをつけたその日から使えることにして、同じ計算をやり直します。 現実にはできません。未来を見ないと分からない情報を、先に渡してあげるという反則です。 それでも計算はできます。

結果です。

遅れあり（現実） 遅れなし（未来が見える）
A 構造で乗る 0/22・PF 1.25・勝率 48.1% 0/22・PF 1.10・勝率 37.6%
B 直近高値の上抜けで買う 0/22・PF 1.06・勝率 48.6% 0/22・PF 1.13・勝率 51.1%
C 安値割れで早く降りる 0/22・PF 1.05・勝率 32.3% 0/22・PF 1.36・勝率 37.2%

未来を見せても、0/22 のままでした。

しかも A は、勝率が 48.1% から 37.6% に下がっています。 早く入れるようになったぶん、まだトレンドになっていないところを買ってしまうからです。

「後から見れば分かる」は、本当でした。 けれど、その「後から」を先に渡してあげても、結果は変わりませんでした。

これは、この連載でこれまで扱ってきた落とし穴とは種類が違います。 第2回は「1回あたりは良いのに取引が少なすぎる」、第3回は「勝率が高いのに大きく沈む」、 第4回は「速いのに届かない」でした。どれも手法の中の話です。

今回は、「そもそも後出しなら勝てるはずだ」という前提そのものを試して、外れました。

誤解のないように、線を引いておきます

💬 読者の疑問 「未来を見せても勝てないということは、この現象は何をしても勝てない、ということですか？」

そこまでは言えません。 線を引いておきます。

ここで渡したのは「高値・安値の位置を数日早く知る」ことだけです。 「どの取引をするか選ばせてあげた」わけではありません。

もし「勝った取引だけ選ぶ」ことを許せば、当然どんな手法でも勝ちます。 それは検証ではなく、ただの後出しです。ここでやったのは、 ルールは固定したまま、情報だけ数日先取りさせるという限定的な反則です。

「あらゆる後知恵が無意味だ」という話ではありません。 言えるのは、この現象の敗因は"気づくのが遅いこと"ではなかった、ということだけです。

7. 「でも、効いた時は本当にあったよね」

ここまで読んで、「高値と安値の切り上がりで大きく取れたことがある」と思った方へ。その記憶は正しいです。

さきほどの 2012年12月5日の取引は、+34.0% でした。 第4回の MACD が同じ相場で取った +15.8% より、大きいのです。 入るのは10営業日遅かったのに、長く持てたぶん取り分は大きかった。 「トレンドが続く限り乗る」という考え方は、この局面では確かに機能しています。

そして、いちばん大きな負けはこれです。

2015年8月18日に買い、8月25日に降りて −14.8%。 中国ショックの週です。「高値も安値も切り上がっている」と判定された直後に、相場が崩れました。

問題は、それが「効く時」かどうかを事前には分からなかったことです。 2012年12月4日の「上昇トレンド成立」と、2015年8月17日の「上昇トレンド成立」は、 その時点では見分けがつきません。どちらも「高値と安値がそろって切り上がった」という、同じ形です。

「見分けられない」は、想像ではなく実測です

「効く時を事前に選べばいい」という話は、たいてい言いっぱなしで終わります。 けれどこのリポジトリには、「効く時と効かない時を事前に振り分けようとして、失敗した記録」が積み上がっています （相場局面の予測を独立に6回／カレンダー条件／VIX／月末条件──いずれも不発）。

「見分けられないと思います」ではなく、「見分けようとして、これだけ失敗しました」と言えます。

正直に書いておくこと

1,260通りを全部計算したので、いちばん見栄えのする組み合わせも分かっています。 前後2本・直近3つで判定・20日で機械的に降りる・手数料ゼロ。 これで買って放置に勝った開始日は 22回中1回です。

第4回の MACD では、いちばん良い組み合わせが 22回中10回まで行きました。 今回は、掃引しても逃げ場そのものがありません。 しかもその1回も、手数料を5bps入れた瞬間に 0/22 に落ちます。

8. まとめ──「指標が悪いのでは」への答え

高値切り上げ・安値切り上げによるトレンド判定は、次の形に落ち着きました。

指標を一つも使わなくても、結論は同じだった（0/22）。 下げからは、はっきり逃げられていた（−35〜−38% 対 −61.3%）。 20年のうち48%の日は、買って放置に本当に勝っていた。 効いた瞬間も、確かに実在した（2012年12月・+34.0%・MACDより大きい）。 前後何本で見るかを6通り変えても、12通りすべてが 0/22 だった。 そして──高値・安値の位置を数日先に教えてあげても、0/22 のままだった。

第1回の「乗る・降りる」、第2回の「安く拾う」、第3回の「売られすぎを買う」、 第4回の「指標を速いものに替える」に続いて、 今回の「指標そのものをやめる」でも、結論は同じでした。

乗っても、絞っても、押し目を待っても、逆張りしても、速くしても、指標をやめても、買って放置には届かなかった。

ここまで来ると、問題は指標の選び方ではないことがはっきりします。 売買のルールは、それが何であれ「持っている時間」を必ず削ります。 削られた時間の中で市場が上げれば、その上げは手に入りません。 上げ相場に居続けることが、いちばん強い。売買が上手いかどうかとは、別の話です。

そして今回いちばん残しておきたいのは、§6 の結果です。

チャートを開くと、高値と安値の切り上がりは目に見えて明らかです。 「なぜこれが分からなかったのか」と思うほど、はっきり見えます。 その感覚は間違っていません。後から見れば、本当に明らかなのです。

けれど、その「明らかさ」は右側が描き終わったチャートが作っています。 そして──ここが今回の実測結果ですが──右側を先に見せてあげても、成績は変わりませんでした。

つまり問題は「気づくのが遅い」ことですらなかった。 気づいたところで、市場にいない時間は取り返せない、というだけの話でした。

この記事が相手にしているのは、マーケットストラクチャという考え方そのものではありません。 「効いた事例だけが記憶と発信に残る」という構造のほうです。 2012年12月に拾えた +34.0% は記憶に残り、2015年8月の −14.8% は、たいてい語られません。 そして「後から見れば明らかだった」という感覚自体は本物なので、なおさら反証されにくい。 その非対称を、自分の手元のデータで一度ほどいてみた、というのがこの記事でした。

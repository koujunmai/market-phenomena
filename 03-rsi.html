「売られすぎ」は買いなのか──勝率8割でも、買って放置には届かない

0. この記事の立ち位置

ここまでの2回は、どちらも「上がっている流れに乗る」やり方でした。

  • 第1回：移動平均クロス。ゴールデンクロスで乗り、デッドクロスや線割れで降りる。→ 買って放置に 0/22
  • 第2回：移動平均への押し目買い。上昇トレンドの途中、線まで押したところを安く拾う。→ 0/22

乗っても、絞り込んでも、安く拾っても、勝てませんでした。 ここまで来ると、多くの人が次にこう考えます。

「上がっているものを追いかけるから負けるんだ。 逆だ。みんなが投げ売りしている、売られすぎのところを買えばいい。 RSIが30を割ったら買い、70を超えたら売る。これがいちばん基本のやつだろう」

これは、株の入門書やチャート解説にほぼ必ず出てくる形です。しかも今回は、これまでの3本とは性質が違います。 第1回・第2回はどれも順張り（流れに乗る）でしたが、今回は初めての逆張りです。

そして先に言っておくと、今回の結果はこれまでで一番"惜しく"見えます。 勝率は跳ね上がりました。ある形では 10回中8回勝っています。 それでも結論は同じでした。その理由が、この回のいちばんの見どころです。

使う数字の土台は前回までと同じです（詳しくは第0回・第1回で扱っています）。

  • 対象は 1306（TOPIX連動ETF） と、国内の中〜大型株 552銘柄。期間は 2005-11 〜 2026-07。
  • 個別552銘柄には生存者バイアスがあるので、絶対的な成績は出さず、比べ方（相対比較）だけに使います。 主な結論は、バイアスのない指数（1306）で出します。
  • 比較の基準は 「買って放置」。最初に一度だけ買って、あとは何もせず持ち続けるだけ。 チャートも見ないし、売買の判断もしません。積立（毎月コツコツ買う）とは別物です。

先に、言葉の意味を2つだけ確認させてください。

  1. この記事の数字は、ことわりのない限りすべて「指数（1306）」のものです。 個別株ではありません。
  2. これから「勝てない」「届かない」と書くのは、"お金が減る"という意味ではありません。 今回の手法は、お金はちゃんと増えます。問題は、同じ期間ただ1306を買って放置していたほうが、もっと増えていたこと。 ここでの「負け」は、損失ではなく"取りこぼし"です。これは記事の途中で金額で確かめます。

1. 「RSI30割れで買う」を、計算できる形にする

RSI は、ざっくり言えば 「最近の値動きのうち、上げがどれくらいの割合を占めているか」を 0〜100 で表した指標です。 下げ続けると数字が小さくなり、上げ続けると大きくなります。 30を割ったら「売られすぎ」、70を超えたら「買われすぎ」、というのが定番の読み方です。

💬 読者の疑問 「RSIって計算方法がいくつかあるって聞きました。それで結果が変わるのでは？」

変わりませんでした。今回は最も広く使われる Wilder（ワイルダー）方式を主結果に据え、 もう一つの流儀（単純平均方式）でも計算し直して、結論が変わらないことを確認しています。 計算方式の違いに逃げ道はありません。

そのうえで、買い方を2通り用意しました。ここが今回の工夫です。

買い方 誰が言う形か
① 即買い RSIが30を割った、その日の翌朝に買う 「30を割ったら買い」という、いちばん素直な形
② 回復確認 RSIが30を割ったあと、ふたたび30を上抜けた翌朝に買う 「落ちるナイフを掴むな。反発を確認してから入れ」という定番の助言

①だけを検証すると、必ず「それは下手なやり方だ、②が正しい」と言われます。 なので最初から両方回しました。どちらも計算の前に条件を登録して凍結してあります。

出口は、主張どおり「RSIが70を超えたら」。持っている間にRSIが70に達したら、翌朝の寄りで売ります。 「30で買って70で売る」という、言われているままの形です。 （あわせて「1日で降りる」「5日で降りる」など、機械的に日数で降りる形も全部試しています。）

RSIの期間は 7・9・14・21・25日、買いの閾値は 20・25・30 を掃引しました。 全部で30通り × 出口6通り × 手数料5水準 = 900通りを計算しています。

ちなみに「70を超えたら売り建てする（空売り）」は、今回は扱っていません。 巷で言われる「70超えで売り」は、ほとんどの場合「持っている株を利確する」という意味で使われており、 新規に空売りするのは別の話になるからです。これは正直に、検証していない範囲として書いておきます。

2. まず、単体の成績を見てみる──勝率が、跳ね上がる

指数（1306）で回した結果です（出口＝RSI70到達・往復5bpsの手数料を引いています）。

買い方 取引数 勝率 1回あたり平均 PF
RSI14・30割れ・即買い 16 62.5% +1.42% 1.36
RSI14・30割れ・回復確認 16 81.2% +2.44% 1.65
RSI9・30割れ・即買い 38 65.8% +1.47% 1.54

勝率62〜81%。 ここまでの2回と並べると、違いは一目瞭然です。

第1回のクロスが40.2%、第2回の押し目が27.8%だったのに対し、 RSIの逆張りは、10回買えば6〜8回は勝っていました。

💬 読者の疑問 「ほら、やっぱり逆張りのほうが当たるんじゃないですか。勝率8割って相当では？」

そのとおりです。「逆張りは当たりやすい」という体感は、データの上でも正しい。 ここは正直に認めます。しかも「落ちるナイフを掴むな（＝②回復確認）」という助言も、 勝率を 62.5% → 81.2% に、PFを 1.36 → 1.65 に、ちゃんと改善させています。 言われていることは、間違っていませんでした。

もしここで話を止めれば、「RSI30割れの逆張りは、反発を確認してから入れば勝率8割」という記事が書けます。 ──ですが、比較する相手を置くと、また景色が変わります。

3. 「買って放置」と比べる──勝率8割でも、0勝

これまでと同じ土俵です。開始した年を1年ずつずらして 22通り、 それぞれ「1306でRSI逆張りをした場合」と「1306を買って放置した場合」の、どちらが期末に多く残ったかを数えます。

買い方 RSI逆張りの中央値 買って放置の中央値 RSIが勝った開始日
RSI14・即買い +51.8% +159.1% 0 / 22
RSI14・回復確認（勝率81%） +67.3% +159.1% 0 / 22
RSI9・即買い +48.3% +159.1% 0 / 22

22通りのどこから始めても、一度も上回りませんでした。 900通りの組み合わせ全体で見ても、勝った開始日が過半を超えたものは一つもありません。 いちばん良い組み合わせでも 22回中4回です。

中央値で金額にすると、100万円を投じて、

  • 買って放置 → 約 259万円
  • RSI30割れ・即買い → 約 152万円
  • RSI30割れ・回復確認（勝率81%）→ 約 167万円

ここで大事なのは、RSI逆張りでも、お金は減っていないということです。100万円は152万円に、ちゃんと増えています。 損をしたわけではありません。 ただ、同じ期間、何もせずただ1306を持っていれば259万円になっていた。 その差の 約107万円は、"損失"ではなく"取りこぼし" です。

手法に意味があるかどうかは、「勝ったかどうか」では決まりません。 何もしない人に勝てたかどうかで決まります。 10回中8回勝っていても、買って放置した人に届いていないなら、 その手法がやったことは「手間をかけて成績を下げた」ということです。

勝率8割は、資産が増えることを保証しない。 これが、この回でいちばん見てほしいことです。

4. 出てくる反論を、先に一緒に潰しておく

「30じゃ甘い。20まで待て」

もっともな指摘です。実際、閾値を厳しくすると1回ずつの成績は良くなります。

条件 取引数 勝率 PF 市場にいた割合 勝った開始日
RSI9・30割れ 38 65.8% 1.54 45.3% 0 / 22
RSI9・25割れ 29 58.6% 1.56 33.8% 0 / 22
RSI9・20割れ 21 81.0% 2.56 22.8% 0 / 22

20まで待つと、勝率81%・PF2.56。1回ずつの取引は、明らかに良くなっています。 ところが市場にいる割合が45%から23%へ半減し、買って放置への勝敗は 0/22 のままでした。 （しかもRSI14で20まで待つと、20年で取引がたった5回になり、PFは0.59まで落ちます。 条件を厳しくするほど、数字はサンプル不足で暴れ出します。）

第1回で「条件を絞り込んでも改善しない」と書きましたが、逆張りでもまったく同じ形になりました。

「30を上抜けてから買え（落ちるナイフを掴むな）」

これは前述のとおり、部分的に正しいです。RSI14では勝率が 62.5% → 81.2%、PFが 1.36 → 1.65 に改善しました。 ただし、買って放置への勝敗は 0/22 のまま変わりません。 さらに、RSI9で同じことをすると、PFは 1.54 → 1.23 に悪化します。改善は一貫してすらいませんでした。

助言としては正しい。それでも、勝敗は変わらない。 この記事で何度も出てくる形です。

「シグナルが出ていない間は現金だろう。市場にいる時間が違う」

正当な指摘です。そこでシグナルが出ていない間のお金を、同じ1306に置いた場合でも計算しました。

買い方 「RSI＋余りは指数」の中央値 買って放置の中央値 勝った開始日
RSI14・即買い +158.3% +159.1% 2 / 22
RSI14・回復確認 +158.3% +159.1% 2 / 22
RSI9・即買い +157.1% +159.1% 1 / 22

ほとんど互角まで近づきます。ただしこれは、手法が強いという意味ではありません。 「RSIを見ずに、ただ指数を持ち続けていた場合とほとんど同じ結果」という意味です。 残った差は、売買のたびに払った手数料ぶんです。

「暴落したら買って放置は大損する。RSIなら逃げられるのでは」

部分的には、そのとおりでした。ここは手法の実在する利点なので、正直に書きます。 買って放置は、2007〜2009年の下げで最大 −61.3% まで沈んでいます。 一方、RSI逆張り（即買い）が抱えた最大の落ち込みは −48.9%。 シグナルが出ていない間は現金でいるぶん、確かに浅く済んでいます。

ただし、その −48.9% の中身がひどい。 これは次章で見ます。

「手数料が厳しすぎるのでは」「配当を入れれば放置が有利なだけでは」

手数料をゼロにしても、買って放置を上回った組み合わせは 0 でした。 配当については、今回の計算は分配金を含めておらず、買って放置を過小評価しています。 つまり、はじめから手法側に甘い比較です。それでも 0/22。配当を戻すと結論はより強くなる方向にしか動きません。

「同じ回数だけ、ランダムに買ったら？」

同じ回数・同じ保有期間で、日付を無作為に選んで買った場合（1,000回試行）と比べました。 結果は、パーセンタイルで 24 / 36 / 44。3つとも50を下回っています。

つまり 「売られすぎを狙って買う」ことは、日付をサイコロで決めて買うのに勝てませんでした。 これは今回いちばん厳しい数字かもしれません。

「個別株ならどうなんですか」

同じやり方を国内の中〜大型株552銘柄でも回し、こちらも 0/17 でした。 ただし個別株のデータには生存者バイアス（今まで生き残った銘柄しか入っていない）があります。 今回は逆張りなので、このバイアスは手法にとって逆風に働きます。 そのため「個別で負けた」という結果は、指数ほど強い証拠にはなりません。判定には使っていません。 （生存者バイアスの話は第0回でくわしく扱っています。）

5. なぜ勝てないのか──「たまに来る1回」が、勝率をぜんぶ持っていく

前回（押し目買い）の負け方は「1回ずつは勝つが、市場にほとんどいない」でした。 今回は違います。 RSI逆張りは市場に 43% ほどいますし、1回ずつも勝っています。 それでも届かない理由は、負ける時の大きさにあります。

これを、たった1回の取引で見てください。

2007年8月3日。 相場が崩れ始め、RSIが30を割りました。「売られすぎ」です。ルールどおり買います。

そこから起きたことは、ご存じのとおりです。サブプライム、そしてリーマンショック。 しかしルールは「RSIが70に戻るまで売るな」と言っています。 RSIが70に戻ったのは、1年7か月後の2009年3月27日。402営業日、下げ相場を丸ごと抱えたまま持ち続けて、 この1回の損益は −48.9% でした。

💬 読者の疑問 「それは買って放置だって同じでは？ あの暴落は誰も避けられなかったでしょう」

まったくそのとおりです。 同じ期間ただ持っていた場合も −49.5%。ほとんど変わりません。

ここが、この回のいちばん大事なところです。 「売られすぎだから買う」という判断は、下げ相場を避ける役には立ちませんでした。 むしろ "売られすぎ"のサインは、下げ相場の入り口でこそ点灯します。 勝率8割の正体は、「小さく何度も勝ち、たまに来る1回で、それまでの勝ちを全部返す」形でした。

そして、もう一つ皮肉なことが起きています。

局面 RSIが30を割った日数 その間に買えた回数
2008年9〜11月（リーマン） 7 / 60日 0回
2020年2〜3月（コロナ） 19 / 39日 1回（−0.7%）
2024年8月（急落） 3 / 21日 1回（+24.0%）

リーマンショックのど真ん中で、買えた回数はゼロです。 なぜかというと、2007年8月に買った玉をまだ抱えていたから。 「売られすぎたら買う」というルールは、本当の大底では、すでに手持ちが埋まっていて買えないのです。

コロナのときも、RSI30割れが39日中19日も続いたのに、実際に買えたのは1回（−0.7%）だけでした。 「暴落したら拾えばいい」は、ルールにした瞬間、思ったようには動きません。

6. 「でも、効いた時は本当にあったよね」──ここが核心

ここまで読んで、「RSIの逆張りで大きく取れたことがある」と思った方へ。その記憶は正しいです。

実際、最大の勝ちは 2024年8月です。8月2日にRSIが25まで落ちて「売られすぎ」が点灯し、 ルールどおり翌営業日＝8月5日の寄り付きで買っています。

その8月5日が、日経平均が1日で12%下げた「令和のブラックマンデー」当日でした。 買った値段から、その日の終値までに −5.4%。まさに落ちるナイフを掴んでいます。 それでも最終的には、RSIが70に戻った2025年7月まで持って +24.0% で終えました。 売られすぎを買って、見事に取れた1回です。これは本当にありました。

年別に見ると、こうなります。

この図には、今回の手法の性格がそのまま出ています。 22年のうち9年は、1回も買っていません（20年で16回しか売買がないので、そうなります）。 そして買った年のうち5年がマイナス。 右端のいちばん高い緑（2024年 +24.0%）と、左のいちばん深い赤（2007年 −48.9%）は、 どちらも「RSIが30を割ったので買った」という、まったく同じ判断の結果です。

問題は、それが「効く時」かどうかを、事前には分からなかったことです。 2007年8月の30割れと、2024年8月の30割れは、その時点では見分けがつきません。 片方は −48.9%、もう片方は +24.0% でした。

数字でも確認できます。貢献の大きかった上位3回の取引を除くと、 PF 1.36 だった即買いは 0.62 まで落ちて1を割り込みます。 さらに前半（2005〜2016年）だけを取り出すと、PF は 0.57。 20年ぶんの見かけの成績は、実質的に数回の大当たりで成り立っていました。

なお、直近24か月に絞ると取引は 1回だけです。 20年で16回しか売買がないので当然ですが、この期間の成績で何かを判断することはできません。 「最近も効いています」と言えるだけの回数が、そもそもありません。

「見分けられない」は、想像ではなく実測です

「効く時を事前に選べばいい」という話は、たいてい言いっぱなしで終わります。 けれどこのリポジトリには、「効く時と効かない時を事前に振り分けようとして、失敗した記録」が積み上がっています （相場局面の予測を独立に6回／カレンダー条件／VIX／月末条件──いずれも不発）。

「見分けられないと思います」ではなく、「見分けようとして、これだけ失敗しました」と言えます。

7. まとめ──「勝率が高い」を、救いにしない

RSI30割れの逆張りは、次の形に落ち着きました。

勝率は 62〜81%。10回買えば6〜8回は勝っていた。 「反発を確認してから買え」という定番の助言も、確かに成績を良くした。 暴落時の落ち込みも、買って放置よりは浅かった（−48.9% 対 −61.3%）。 効いた瞬間も、確かに実在した（2024年8月の急落・+24.0%）。 けれど、それが効く時かどうかを事前に見分ける手段は見つからず、 たまに来る1回（2007年8月・−48.9%）が勝ちを全部返して、 手元に残った資産は、ただ買って放置していた場合に届かなかった（0/22）。

第1回の「乗る・降りる」、第2回の「安く拾う」に続いて、今回の「売られすぎを買う」でも、結論は同じでした。 乗っても、絞っても、押し目を待っても、逆張りしても、買って放置には届かなかった。

今回とくに気をつけたいのは、「勝率が高い」という手応えです。 前回は「PFが高いのに勝てない」でしたが、今回はもっと分かりやすく、 10回中8回勝っているのに勝てない。

勝率は、勝った回数しか数えません。1回あたりいくら負けたかは入っていません。 だから「よく当たる」やり方ほど、負ける時の大きさが見えなくなります。 そして、よく当たるからこそ、やめられなくなります。 勝率の高さは救いではなく、むしろ手放しにくくさせる性質でもある、というのが今回の実感でした。

この記事が相手にしているのは、RSIという指標そのものではありません。 「効いた事例だけが記憶と発信に残る」という構造のほうです。 2024年8月に拾えた+24%は記憶に残り、2007年8月から1年7か月抱え続けた−48.9%は、 たいてい語られません。その非対称を、自分の手元のデータで一度ほどいてみた、というのがこの記事でした。

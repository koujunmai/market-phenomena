ここまでの8回で、移動平均のクロス、押し目買い、RSI、MACD、高値の切り上がり、 ボリンジャーバンド、損切り、地合いフィルタを調べてきました。 どれも「買って放置」には届きませんでした。

そのすべてに、ひとつ共通していたことがあります。 測ってきたのは、全部「上がる」か「下がる」かを言う合図でした。 ゴールデンクロスは買い。RSI30割れは買い。200日線の下は休む。向きが決まっています。

けれど、相場の世界でよく言われることの中には、向きを言わない主張があります。

値動きが極端に縮んだ後には、大きな相場が来る。エネルギーを溜めているから。 溜めたものは、いずれどちらかに放たれるはず。

これは「上がる」とは言っていません。「動く」としか言っていない。 今回はこれを測ります。連載で初めて、方向を持たない主張を扱う回です。

先に、今回の見どころを言っておきます。

前兆は、実在しました。 値動きが縮んだ日の翌日は、同じくらい縮んだ他の日と比べて、確かに大きく動いていました。 5つの測り方すべてで、比較対象の上位5%に入っています。

この連載で「巷の主張が成り立った」と書くのは、これが初めてです。

それでも、売買としては 0/22 でした。 理由は単純で、上に抜ける確率と下に抜ける確率が、ほぼ同じだったからです。 動くことは事前に言えました。どちらへ動くかは、言えませんでした。

みっつ。 向きを当てる方法を、本検証では見つけられませんでした。 見つからなかったのであって、存在しないことを証明したわけではありません。 私が試した範囲では出なかった、という意味です。

使う数字の土台は前回までと同じです（詳しくは第0回・第1回で扱っています）。

3. 前兆は、実在した

ここが今回の中心です。そしてこの連載で、巷の主張が成り立った初めての箇所です。

何と比べるかで、答えが真逆になる

「縮んだ後は大きく動く」を確かめるとき、比較対象の選び方でまったく違う答えが出ます。

素の平時と比べる——つまり「普通の日の値動き」と比べると、 縮んだ日の後はむしろ小さいという結果になります。当たり前で、 値動きが縮んでいる時期というのは、そもそも相場全体が静かな時期だからです。 これで「効かない」と結論するのは、フェアではありません。

なので、比較対象を作り直しました。

同じくらい縮んでいたのに、Inside Day ＋ NR4 にはならなかった日

縮み具合を10段階に分け、合図の出た日と同じ構成になるように、 合図の出ていない日から同数を引き直します。これを1,000回繰り返します。 「静かな時期だったから」では説明できない差だけが残る仕組みです。

この比較対象を作ることは、計算を始める前に決めてありました。 そして私は、この比較では差がほとんど消えるだろうと予想を書いていました。

予想は、外れました

翌日から k 日間の値動きの大きさを、その時点の「直近10日の平均的な値幅」で割った値です。

5つの測り方すべてで、比較対象の上位5%に入りました。 1日後と3日後にいたっては、1,000回の比較すべてを上回っています。 個別552銘柄でも、5つすべてで最上位でした。

念のため、「10段階に分けたのが粗いから差が出たのでは」という可能性も潰しました。 50段階、200段階に細かくしても、差は縮むどころか広がりました。

さらに、「NR4 の日は、その直前が荒れていた日に偏るのでは」という説明も試しました。 実際に偏っていました（前日の値幅は普通の日の1.3倍あります）。 そこで縮み具合と前日の荒れ具合の両方でそろえて比べ直したのですが、 差はやはり消えず、むしろ大きくなりました。

「縮んだ後は動く」は、私が試した範囲では、本当でした。 そしてなぜそうなるのかは、分かっていません。 理由は特定できていない、と書いておきます。

ただし、3つの留保

ひとつ。数字はすべて 1.0 を下回っています。 1.0 は「直近10日の平均的な値幅と同じ」という意味です。 つまり縮んだ日の翌日は、直近の平均よりは小さいままです。 「エネルギーが放たれて大相場になる」という語感とは、ずいぶん違います。 正確に言えば——縮んだ後は、思ったほどは縮まなかった、です。

ふたつ。素の平時と比べれば、負けています。（5日後で 0.944 対 0.984） だから「縮んだ後は動く」と言うときは、何と比べての話なのかを必ず添える必要があります。

みっつ。これは向きの話を一切していません。 次の節がそこです。

5. 「買って放置」と比べる

手法に意味があるかどうかは、「勝ったかどうか」では決まりません。 何もしない人に勝てたかどうかで決まります。

そして「いつ買い始めたか」で結果は変わるので、 開始時期を1年ずつずらした22通りで、対にして比べます。

手法の中央値 買って放置の中央値 勝った回数
A ID＋NR4 +16.2% +159.1% 0 / 22
B NR4 のみ +72.5% +159.1% 0 / 22
C 安値割れで撤退 +21.0% +159.1% 0 / 22

100万円で言い換えます。 A で 116万円、B で 173万円、C で 121万円。何もしなければ 259万円でした。

ここは誤解されやすいので、はっきりさせておきます。 116万円は、減っていません。増えています。 この手法をやった人は損をしていない。ただ、何もしなかった人に置いていかれただけです。 差の143万円は「損失」ではなく「取りこぼし」です。

そして、逃げ道は全部ふさいであります。

  • コストを 0% にしても 0/22。 売買コストのせいではありません。
  • 市場にいない89%の資金を、まるごと指数に置いても 0/22（中央値 +152.1% 対 +159.1%）。 「現金で寝かせていたから負けた」では説明できません。
  • 配当を戻しても 0/264。 本稿は分配金を含めておらず、これは買って放置を過小評価しています。 つまり手法に甘い比較になっている。それでも届きません。
  • 個別552銘柄でも 0/17（中央値 +23.4% 対 +237.7%）。
  • ランダムに買った場合と比べると、上位 67〜80% の位置。 ランダムよりは上ですが、「合図の形が効いている」と言える水準ではありません。 （NR4 だけの形は、個別ではランダム1,000回のすべてを下回りました。）

6. なぜ買えないのか──向きが、五分だから

第0階では前兆が実在した。第1階では 0/22 だった。 矛盾しているようですが、間に入る数字を見ると一本につながります。

縮んだ日の翌日、高値を上抜ける確率は 60.7%。安値を下抜ける確率は 57.3%。

ほぼ同じです。

これが今回のすべてです。縮んだ日の翌日は、上も下も、だいたい同じ確率で破られます。 「動く」ことは事前に言えました。しかしどちらへ動くかは、まったく言えていません。

k 日後の終値が上がっている割合も 48.8%〜58.8% の間で揺れ、 比較対象に対する位置も 23.8% から 90.7% までばらつきます。一貫した偏りが出ません。

では、PF 1.21 は何だったのか

上抜けで買った売買は PF 1.21 でした。向きが当たっていないなら、なぜ勝っているのか。

下抜けで売る側（ショート）を計算すると、答えが出ます。

手仕舞い 1日 3日 5日 10日 20日
PF（指数） 0.99 0.83 0.74 0.77 0.73

すべての手仕舞いでマイナスです。 きれいに非対称でした。

もし「向きが当たっている」なら、上も下も同じくらい効くはずです。 実際には上だけが勝ち、下は全部負ける。 これは合図が方向を当てているのではなく、上がる市場に居ただけということです。

PF 1.21 の正体は、この20年間、日本株が上がったことでした。 そして市場に11%しかいなかったので、ずっと居た人には届きません。

7. 出てくる疑問を、先に潰しておく

💬 読者の疑問 「市場にいたのが11%なのに、11%ぶんの成績と比べるのはおかしいのでは」

筋の通った疑問です。そして、これは計算する前から予想がついていたので、答えを用意してあります。

合図が出ていない89%の期間、資金をまるごと 1306 に置いた場合でも計算しました。 「手法＋余った資金は指数」対「全部指数」なら、市場にいる時間の差は消えます。

結果は 0/22（中央値 +152.1% 対 +159.1%）。 市場にいる時間をそろえても、届きませんでした。

💬 読者の疑問 「配当を入れれば、結果は変わるのでは」

そのとおりで、しかも buy&hold 側に有利に変わります。 本稿の価格データには分配金が入っていません。買って放置は資金の100%をずっと市場に置くので、 配当を入れるといちばん得をするのは買って放置です。

年1.5%と2.0%を仮定して戻した計算もしてあり、264通りすべてで手法が負けました。 つまり本稿の比較は、手法に甘い側に寄っています。それでも届きません。

💬 読者の疑問 「最大の下げが浅いなら、それ自体に価値があるのでは」

その通りで、実際に浅くなっています。 A の最大の下げは −21.8%、C は −19.0% です。

ただし買って放置の下げと直接は比べられません。 手法の側は「112回の売買を並べたときの落ち込み」、買って放置は「毎日の評価額の落ち込み」で、 測り方が違うからです（同じ期間の買って放置は、日々の評価額でいえば一度 −61.3% まで沈んでいます）。 そして手法の下げが浅いのは市場に11%しか居ないのだから当然で、手法の手柄とは言い切れません。 そして本稿が測ったのは「20年後にいくらになっていたか」の一点です。 下げの浅さそのものに価値を置く人にとって、この記事は答えを出していません。

8. 「では、こうすればいいのでは」を、実際にやってみる

ここまで読むと、当然こう思うはずです。「条件が緩いだけでは。絞り込めばいいのでは」 実際にやってみます。

① Inside Day を足して絞る（巷で言われているとおりに）

「NR だけでは弱い。Inside Day も重なっているほうがいい」——これは実際に効きました。

売買は 462回から 112回に減り、PF は 1.18 から 1.21 に上がりました。 そして勝敗は 0/22 のままです。

ついでに分かったことがあります。この2つの条件は、独立していません。 NR4 が成立している日は、Inside Day も成立している確率が 2.4〜3.4倍に上がります。 「2つの条件が揃った」と言っても、2つぶんの根拠にはなっていないということです。

「条件を足すと1回あたりの質は上がるが、勝敗は変わらない」—— これを見るのは連載で5度目です。パーフェクトオーダー（第1回）、MACD（第4回）、 高値の切り上がり（第5回）でも、同じことが起きていました。

「直近4日でいちばん狭い」を、7日・10日・20日でいちばん狭い、に変えてみます。 上抜けを待つ日数も1日・2日・3日に変えます。組み合わせて12通り。

12通り、例外なく 0/22 です。 厳しくするほど合図は減り、市場にいる時間も減り、買って放置から遠ざかります。

安値割れを"唯一の"出口にすると、PF は 11.16 になります。 数字だけ見れば連載最高です。

第7回で触れた新高値買いでも同じ事故が起きていました。 20年で3回しか売買が成立せず、288回の合図を全部見送ってしまう、というものです。 今回はその再演でした。だから主結果は「5日で手仕舞う、ただし安値を割ったらそこで降りる」 という、どちらか先に来たほうの形にしてあります。 それが C で、0/22 です。

④ 全部の組み合わせを見れば、どこかに当たりがあるのでは

買って放置と対戦させたのは168通りです。そのうち——

  • 過半の開始時期で勝った組み合わせ: 0通り
  • 1通りでも勝ちがあった組み合わせ: 24通り。そしてその24通りは、全部③の事故セルでした。
  • 個別552銘柄では、1通りでも勝ちがあった組み合わせが 0。

掃引して出てきた良いセルを選んで「これが効く」と書くことは、この連載では禁止しています。 それをやったら、私がこの連載で批判している行為そのものになるからです。

9. 効いた日、正反対に動いた日

平均では届かない。しかし常に効かないわけではありません。 そこは正確に書きます。

大きく効いた3回

  • 2012-11-15 +6.85%（衆院解散の前後）
  • 2024-08-09 +6.31%
  • 2024-03-15 +5.33%

正反対に動いた3回

  • 2024-07-31 −13.67%。上抜けたので買い、その翌週の暴落を丸ごと被りました。
  • 2007-08-09 −7.85%
  • 2013-05-22 −6.59%（異次元緩和のあとの急落の初日）

年で見ると、22年のうち7年がマイナスです（2007・2010・2011・2013・2018・2020・2025）。 いちばん悪い2010年は1回あたり −3.06%。 「たまに負ける」ではなく、「年単位で負ける年が3年に1年ある」という頻度です。

そして、いちばん効きそうな場面では合図が出ていない

これは書いておくべきだと思いました。

リーマン・ショック（2008年9〜10月）、2018年12月の急落、コロナ・ショック（2020年2〜3月）、 2022年3月——この4つの局面で、合図は1件も出ていません。

「大相場の前には値動きが縮んでいたはずだ」という語りは、 少なくともこの4つの局面については、当てはまりませんでした。

もっとも、これは特定の事例の話です。判定には使っていません（判定は §5 の 0/22 と §3 の対照だけで決めています）。 効いた事例のほうも同じで、「こういう時は狙える」とは書けません。事前には分からないからです。

10. 結論

縮んだ後は動く。これは本当でした。

同じくらい縮んだ他の日と比べて、合図の出た日のほうが確かに大きく動いています。 5つの測り方すべてで上位5%に入り、1日後と3日後は1,000回の比較すべてを上回りました。 細かく分け直しても、別の説明を当てはめようとしても、差は消えませんでした。 この連載で、巷の主張が成り立ったのは今回が初めてです。

それでも、売買にはなりませんでした。

上に抜ける確率が 60.7%、下に抜ける確率が 57.3%。ほぼ同じです。 動くことは分かる。向きは分からない。 向きが分からないまま片側に賭ければ、残るのは市場の平均だけで、 しかも市場にいるのは11%の時間だけです。

条件を厳しくしても 0/22。待つ日数を変えても 0/22。 コストを0にしても、待機資金を指数に置いても、配当を戻しても、0/22 でした。

100万円が116万円になりました。減ってはいません。 ただ、何もしなければ259万円でした。

そして、ここがこの連載の中心にある話です。

前兆が実在することと、それで利益が出ることは、別のことでした。 「動く」と分かっても、「どちらへ」が分からなければ、賭けにはなりません。

これまでの8回は「効いたように見えるが、実は効いていなかった」という形でした。 今回は違います。効いていました。実在しました。それでも届きませんでした。

効く時は実在します。今回は、実在することを数字で示せました。 問題は、その先に進む方法が見つからなかったことです。 見分けられない以上、手元に残るのは全部の平均だけで、その平均は買って放置に届きませんでした。

補足: 今回測ったのは、日足の Inside Day ＋ Narrow Range というひとつの具体形だけです。 ボリンジャーバンドのスクイーズ、ATR の低下、分足での収縮については何も測っていません。 また、第0階の差がなぜ生まれるのかは分かっていません。ここは宿題として残っています。

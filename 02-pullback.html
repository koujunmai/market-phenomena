押し目買いは効くのか──1回ずつ勝っても、指数の放置に届かない

0. この記事の立ち位置

前回（第1回）は、移動平均クロスの話でした。 「ゴールデンクロスで乗って、デッドクロスや線割れで降りる」──つまりトレンドに乗るやり方です。 結果は、どの組み合わせでも、どの降り方でも、「買って放置」に 0/22。 乗っても降りても、勝てませんでした。

ここまで読むと、次の疑問が浮かびます。

乗るのが下手なのではなく、高いところで飛びつくから負けているのでは。 上昇トレンドの途中で、価格が移動平均線まで下がってきたところを買えばいい。 つまり、押し目を拾えば、安く仕込めて勝てるはず。

これはとても自然な発想です。「高値づかみを避けて安く買う」──理屈も通っています。 なので今回も、実際にやってみました。

先に、使う数字の土台を短く（詳しくは第0回・第1回で扱っています）。

  • 対象は 1306（TOPIX連動ETF） と、国内の中〜大型株 552銘柄。期間は 2005-11 〜 2026-07。
  • 個別552銘柄には生存者バイアスがあるので、絶対的な成績は出さず、比べ方（相対比較）だけに使います。 主な結論は、バイアスのない指数（1306）で出します。
  • 比較の基準は前回と同じ 「買って放置」（最初に一度買って、あとは何もせず持ち続けるだけ。積立とは別物です）。

先に、言葉の意味を2つだけ確認させてください（ここを外すと、この記事は正反対に読めてしまいます）。

  1. この記事の数字は、ことわりのない限りすべて「指数（1306）」のものです。 個別株ではありません。押し目買いを、TOPIX連動ETFという「実際に買える1本」に対してやったら、という話をしています。
  2. これから「勝てない」「負ける」と書くのは、"お金が減る"という意味ではありません。 押し目買いでも、多くの場合お金は増えます。問題は、同じ期間ただ1306を買って放置していた場合のほうが、もっと増えていたという点です。 つまりここでの「負け」は、損失ではなく"取りこぼし"のことです。この違いは、記事の途中でもう一度、金額で確かめます。

1. 「押し目買い」を、計算できる形にする

「押し目で買う」と言うとき、人によって思い浮かべる線が違います。移動平均線だったり、 トレンドラインだったり、直近の安値だったり。このうち引く人によって場所が変わる線（トレンドライン等）は、 条件を一つに凍結できないので今回は扱いません。移動平均線への押し目に絞ります。

💬 読者の疑問 「"押し目を買う"って、具体的にどうなったら買いなんですか？ 線に触れたら？ 割れたら？」

今回は、いちばん語られる形──「上昇トレンド中、いったん線まで押して、そこから反発したら買う」を、 次のように定義しました（この条件も、計算の前に登録して凍結してあります）。

  1. その移動平均線が上向きであること（＝上昇トレンドの最中である、という前提）。
  2. 価格（終値）が、いったんその線以下まで押したこと。
  3. 翌日以降、終値がふたたび線を上抜けて反発したこと。→ その翌日の寄りで買う。

そして出口は「線割れ」。持っている間に終値がその線を割ったら、翌日の寄りで降ります。 「押したら反発を確認して買い、線を割ったら降りる」という、押し目買いのいちばん素直な形です。

線の種類は、単純移動平均（SMA）と指数移動平均（EMA）の両方を試しました （「EMAでないと効かない」という声に先回りするためです）。 線の期間は 5・20・25・50・75日を掃引しています。

2. まず、単体の成績を見てみる──これが、意外と悪くない

指数（1306）で、押し目買いを回した結果です（出口＝線割れ・往復5bpsのコストを引いています）。

線 取引数 勝率 1回あたり平均 PF
SMA 25日 133 27.8% −0.20% 0.81
SMA 50日 122 31.1% +0.69% 1.73
SMA 75日 79 36.7% +0.67% 1.68
EMA 50日 213 33.8% +0.37% 1.36
EMA 75日 153 30.1% +0.49% 1.43

浅い押し目（25日線）は、1回ずつでも負けています（PF 0.81）。 ところが深い押し目──50日・75日の線まで待つと、様子が変わります。 PF は 1.4〜1.7。指数の全60通り（線×期間×出口）のうち、32通りでPFが1を超えました。

💬 読者の疑問 「PFが1.7もあるなら、良い手法では？ 1回ずつちゃんと勝ってるってことですよね」

そのとおりです。深く押したところを、反発を確認してから拾うぶん、1回あたりの取引は勝ちやすい。 「安く買う」という発想は、トレード単体で見れば、確かに機能しています。ここは正直に認めます。

もしここで話を止めれば、「押し目買いは、深い線で待てば機能する（PF1.7）」という記事が一本書けます。 ──ですが、前回と同じく、比較する相手を置くと、景色が変わります。

3. 「買って放置」と比べる──PF 1.7 でも、0 勝

前回と同じ土俵で比べます。ここも指数（1306）の話です。 開始した年を1年ずつずらして22通り、 それぞれ「1306で押し目買いをした場合」と「1306を買って放置した場合」の、どちらが期末に多く残ったかを数えます。

主な3つの線での結果です。

線 押し目買いの中央値 買って放置の中央値 押し目が勝った開始日
SMA 25日 −15.8% +159.1% 0 / 22
EMA 20日 +7.9% +159.1% 0 / 22
SMA 75日 +4.0% +159.1% 0 / 22

（この図は「2005年に始めたら」という一つの例です。前の表と、この先の金額は、始めた年を22通りずらした中央値なので、倍率はこの例とずれます。）

じつはこの例は、押し目買いにとってむしろ良かったほうです。2008年の暴落を現金で避け、そこから十数年にわたって買って放置の上を走っていました。ここは正直にすごい。 それでも、2023〜2025年の上昇局面で押し目買いが現金に退いているあいだに、買って放置が一気に伸びて、最後は追い抜かれました（×2.8 対 ×1.5）。 ここでも押し目買いのお金は1.5倍に増えています。損はしていません。ただ、何もせず持っていれば2.8倍でした。

そして、これはあくまで一例です。開始した年を1年ずつずらして数えると──

22通りのどこから始めても、押し目買いが買って放置を上回ったことは、一度もありませんでした（0/22）。

そして今回いちばん効くのは、ここです。 さっき PF 1.68 と出ていた SMA 75日でも、結果は 0/22 です。 1回ずつの取引はちゃんと勝っている（PF 1.7）のに、最後に手元へ残った資産は、 ただ買って放置していた場合に届きませんでした。

中央値で金額にすると、100万円を投じて、

  • 買って放置 → 約 259万円
  • 押し目買い（75日線）→ 約 104万円

ここで大事なのは、押し目買いでも、お金は減っていないということです。100万円は104万円に、ちゃんと増えています。 損をしたわけではありません。 ただ、同じ期間、何もせずただ1306を持っていれば259万円になっていた。 その差の 155万円は、"損失"ではなく"取りこぼし" です。 手間をかけて売買した結果、何もしない人に155万円ぶん置いていかれた──今回の「負け」は、そういう意味です。

手法に意味があるかどうかは、「勝ったかどうか」では決まりません。 何もしない人に勝てたかどうかで決まります。 PF 1.7 で1回ずつ勝っていても、買って放置した人に負けているなら、 その手法がやったことは「手間をかけて成績を下げた」ということです。

「勝率が高い／PFが高い＝儲かる」ではない。 これが、この回でいちばん見てほしいことです。

4. 出てくる反論を、先に一緒に潰しておく

「EMAで、20日あたりを使えば効くのでは」

線の種類（SMA / EMA）を替えても、結論は変わりませんでした。 EMA 20日も、SMA 25日も、SMA 75日も、買って放置には 0/22。 線の引き方の議論に逃げても、勝てるようにはなりません。

「押し目は市場にいる時間が短い。比較が不公平では」

これはもっともな指摘です（実際、押し目は市場にいる割合が低い──後で詳しく見ます）。 そこで、シグナルが出ていない間のお金を、同じ1306に置いた場合でも計算しました。

線 「押し目＋余りは指数」の中央値 買って放置の中央値 勝った開始日
SMA 25日 +150% +159% 0 / 22
EMA 20日 +133% +159% 0 / 22
SMA 75日 +153% +159% 0 / 22

差は縮まりますが、やはり届きません。市場にいる時間を揃えても、 押し目のタイミングを計った売買が、成績を上乗せした形跡は見当たりませんでした。

「コストが厳しすぎるのでは」／「配当を入れれば放置が有利なだけでは」

コストをゼロにしても、買って放置を上回ったセルは 0（10通り × 出口6 × コスト条件でも0）。 配当については、今回の計算は分配金を含めておらず、買って放置を過小評価しています。 つまり、はじめから手法側に甘い比較です。それでも 0/22。配当を戻すと、結論はより強くなる方向にしか動きません。

「同じ回数だけ、ランダムに買ったら？」

同じ回数・同じ保有期間でランダムに買った場合（1,000回試行）と比べると、 浅い押し目（25日）はランダムより悪く、深い押し目（75日）だけはランダムを上回りました。 ただし、そのランダムに勝った 75日ですら、買って放置には 0/22 です。 ランダムより上手に拾えたとしても、放置には勝てない、ということです。

「指数じゃなくて、個別株で押し目買いしたら？」──ここは正直に「分かりません」

💬 読者の疑問 「ここまで全部、指数（1306）の話ですよね。個別株で押し目を拾ったら、結果は違うのでは？」

同じやり方を、国内の中〜大型株 552銘柄でも回しました。結果は指数と同じで、 個別株で押し目買いをしても、その同じ552銘柄を買って放置した場合に負けています。 指数だけが特別、というわけではありません。

ただし、ここで一つ、私の手元のデータの弱点を正直に打ち明けなければなりません。 それが生存者バイアスです。

この552銘柄は、2026年の今まで生き残っている銘柄です。つまり、途中で倒産したり上場廃止になって消えた銘柄は、最初からこのデータに入っていません。

これが、なぜこの質問にとって大事なのか。 指数（1306）は、ゼロにはなりません。 中身が入れ替わりながら、市場全体として残り続けます。 けれど、個別株は、ゼロになることがあります。 そして、「線を割ったら降りる」という押し目買いのルールが 本当に価値を持ちうるとしたら、それはまさに、一つの銘柄が崩れ落ちる前に逃げられた場面のはずです。

ところが──その"崩れ落ちた銘柄"こそ、私のデータからは抜け落ちています。 消えた銘柄は、消えているからです。

つまり、押し目買いが個別株で買って放置に勝てる可能性があるとすれば、それは「破綻を避けられた」場面。 そしてその場面を確かめられるデータを、私は持っていません。

だからこの記事は、個別株については 「勝てなかった」とも「勝てる」とも言い切りません。 言えるのは、「手元のデータの範囲では放置に負けた。ただしそのデータは、手法がいちばん役に立つはずの場面を、 構造的に見られない」ということだけです。ここは"検証不可"として、正直に線を引いておきます。 （この生存者バイアスの話は、連載の第0回でくわしく扱っています。）

5. なぜ勝てないのか──「安く買えた」のに、ほとんど市場にいない

答えは、市場にいる時間の短さにあります。

押し目買いは、「線まで押して、反発したところ」だけを買います。 言い換えると、それ以外の時間は、ずっと現金で待っているということです。

  • 前回の順張り（クロス）は、市場にいる割合がおよそ 6割でした。
  • 今回の押し目（75日線）は、約 30%。25日線でも約 28%。

これが、PF 1.7 と 0/22 が同居するからくりです。 1回ずつのトレードは、確かに質が高い（安く拾えている）。 けれど、その1回に入っている時間があまりに短く、市場の上昇の大半を、現金のまま見送っている。

避けられた下げよりも、現金でいるあいだに取りこぼした上げのほうが、はるかに大きい。 「安く買う」という工夫は、そのぶん"買わない時間"を長くすることと引き換えでした。 そして、この市場では、後者のコストのほうが重かったのです。

💬 読者の疑問 「でも、もっと反応の速い線（たとえばEMAの20日）なら、しょっちゅう買い直すから、 市場にいる時間はもっと長いのでは？ それなら勝てそうですが」

そのとおりで、負け方は一つではありません。速い線（EMA20日）だと、反発のたびに何度も入り直すので、 市場にいる割合は逆に6割まで上がります。ところが、そちらはそちらで買って放置に 0/22。 理由が違うだけです。深い線（75日）は「1回の質は高いが、ほとんど市場にいない」から負け、 速い線（20日）は「市場には結構いるが、1回あたりの上乗せがほぼ無い」から負ける。 後者は、余ったお金を指数に置いた比較（前章）で見たとおり、結局「指数を持ちながら、ときどき手数料を払っている」状態に近づきます。 浅すぎても深すぎても、抜け道にはなりませんでした。

6. 「でも、効いた時は本当にあったよね」──ここが核心

ここまで読んで、「押し目で大きく取れたことがある」と思った方へ。その記憶は正しいです。

年別の成績を見せます。

半分以上の年は負けています（75日線では、20年のうち12年がマイナス）。 そして、勝った年のなかには、劇的に効いた瞬間があります。

  • 3つの線のどれでも、最大の勝ちは 2012年11月19日に買った1回に集中しています （75日線では、翌2013年まで持って +42.6%）。

これはアベノミクス相場の入り口でした（この大当たりが集中する時期は、前回の移動平均クロスの検証とまったく同じです）。 この一度の大相場を拾えていれば、大きく勝てた。それは本当です。

問題は、それが「効く時」だと、事前には分からなかったことです。 実際、貢献の大きかった上位3回の取引を除くと、あのPF 1.68 だった75日線でさえ、PFは 0.66 まで落ちて1を割り込みます。 20年ぶんの見かけの成績は、実質的に数回の大当たりで成り立っていました。

「見分けられない」は、想像ではなく実測です

「効く時を事前に選べばいい」という話は、たいてい言いっぱなしで終わります。 けれどこのリポジトリには、「効く時と効かない時を事前に振り分けようとして、失敗した記録」が積み上がっています （相場局面の予測を独立に6回／カレンダー条件／VIX／月末条件──いずれも不発）。

「見分けられないと思います」ではなく、「見分けようとして、これだけ失敗しました」と言えます。

7. まとめ──「1回ずつは勝っている」を、救いにしない

押し目買いは、次の形に落ち着きました。

深く押したところを拾えば、1回ずつのトレードは、確かに勝てていた（PF 1.7）。 効いた瞬間も、確かに実在した（2012年、アベノミクス相場の入り口）。 けれど、それが効く時かどうかを事前に見分ける手段は見つからず、 市場にいる時間があまりに短くて、手元に残った資産は、ただ買って放置していた場合に届かなかった。

前回の「乗る・降りる」に続いて、今回の「安く拾う」でも、結論は同じでした。 乗っても、降りても、押し目を待っても、買って放置には勝てなかった。

そして今回とくに気をつけたいのは、「1回ずつは勝っている」という手応えです。 PF が 1 を超えていると、「自分のやり方は正しい、あとは続けるだけ」と感じます。 けれどその手応えは、資産が増えることを保証しません。 勝率やPFが高いことは、救いではなく、むしろやめられなくさせる性質でもあります。

この記事が相手にしているのは、押し目買いという手法そのものではありません。 「効いた事例だけが記憶と発信に残る」という構造のほうです。 「あの押し目は取れた」という記憶は残り、「入らずに見送った上昇」は記憶に残らない。 その非対称を、自分の手元のデータで一度ほどいてみた、というのがこの記事でした。

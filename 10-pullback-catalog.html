先に、この記事が言わないこと

使う数字の土台は前回までと同じです。

1. 「押し目」には31通りの言い方がある

「押し目で買え」とだけ言われても、測れません。何を「押し目」と呼ぶかが、人によって違うからです。

棚卸しをしたところ、少なくとも31の異なる言い方がありました。 （棚卸しの原本） たとえば——

  • 25日線・75日線まで押したら買う（アンカー）
  • 高値から3%・5%・8%・10%押したら買う（水準）
  • フィボナッチの38.2%・50%・61.8%戻しで買う（水準）
  • 一目均衡表の転換線・基準線・雲まで押したら買う（動く線）
  • RSI40・50まで下がったら買う（オシレーター）
  • ボリンジャーバンドの−1σまで押したら買う（ボラ）
  • 直近高値をブレイクした後、その水準まで戻ってきたら買う＝リテスト（時間）

本件以前に測ってあったのは、31種類中たった4種類だけでした （25日線=第2回・高値の切り上げ系=第5回・RSI30割れの親戚=第4回・地合いフィルタの一部=第8回）。 残りの27種類は、今回が初めての検証です。

これを整理し、34の定義×2つの入り方（recover / touch）=65セルとして、まとめて測ります。 主な結果は、その中でも代表的な5つで示します。

定義 中身
25日線 25日移動平均まで押したら買う
5%押し 直近20日高値から5%下げたら買う
RSI40 RSI(14) が 40 まで下がったら買う
半値戻し 直近の上げ幅の 50% まで押したら買う（フィボナッチ）
リテスト 250日高値をブレイクした後、その水準まで戻ってきたら買う

2. まず、どれくらい出るのか

判定の前に、そもそも合図が出ているかを見ておきます。 5定義の合図回数は、指数側で 90〜214回（22年間）。少なすぎて測れない、ということはありません。

  • 市場にいる割合は8.8〜21.9%。押し目を待つ形の合図なので、四六時中は出ません。
  • リテストは250日高値のブレイクが前提なので、下げ相場では原理的に発火しません。 この性質が、後の§7で効いてきます。

4. 「買って放置」と比べる

手法に意味があるかどうかは、「勝ったかどうか」では決まりません。 何もしない人に勝てたかどうかで決まります。

定義 手法の中央値 買って放置の中央値 勝った回数
25日線 +0.11% +159.1% 0 / 22
5%押し +0.10% +159.1% 0 / 22
RSI40 +0.23% +159.1% 0 / 22
半値戻し +0.28% +159.1% 0 / 22
リテスト +0.15% +159.1% 0 / 22

主結果5セルだけでなく、65セル全部が 0/22 でした。 指数側では1つでも勝った開始時期を持つセルすら 5つしかなく（それぞれ1勝のみ）、個別552銘柄では65セル全部が0勝です。

逃げ道は先にふさいであります。

  • 市場にいない時間の資金を、まるごと指数に置いても 0/22。 「現金で寝かせていたから負けた」では説明できません。
  • コストを0%にしても結論は同じ。
  • 個別552銘柄でも、65セル全部が 0/17。

ここまでは、これまでの回と同じ結末です。今回はここで終わりません。

5. 保有していた日は、平均的な日と区別がつかない

第2回の宿題は「1トレードの質は良いのに、なぜ0/22なのか」でした。 市場にいる時間が短いから、という説明は分かっていましたが、その先が測れていませんでした。

そこで今回、新しい軸を立てました。

押し目で保有していた日そのものが、「良い日」だったのか。

方法は単純です。手法が保有していた日の、1日あたりリターンを全部集めて平均します。 それを、全営業日の平均リターンと比べます。 「良い日を選んで買えていた」なら、 この差はプラスに、しかもはっきり出るはずです。

定義 差（日次） ブートストラップ95%区間
半値戻し +0.025% [−0.050%, +0.100%]
リテスト +0.015% [−0.057%, +0.087%]
RSI40 +0.011% [−0.084%, +0.103%]
5%押し −0.026% [−0.126%, +0.072%]
25日線 −0.024% [−0.078%, +0.031%]

5定義すべて、区間が 0 をまたいでいます。 65セル全体で見ても、差がプラスなのは63セル中30セル、 中央値はほぼゼロ（−0.003%/日）。プラスとマイナスがほぼ五分に割れています。

これが今回の答えです。

押し目が保有していた日は、平均的な日と統計的に区別がつきません。 「良い日を選んでいたが、市場にいる時間が短くて負けた」のではなく、 そもそも選べていない——市場にいる時間の短さと、日の質の低さは、 同じ現象の2つの側面だったということです。

（余談ですが、前回の第9回で測った「値動きが縮んだ日」では、この同じ手法で 前兆が実在するという逆の結果が出ています。同じ道具で測って、出る現象と出ない現象がある ——それ自体が、この検証の道具が都合よく効いているわけではないことの裏付けにもなっています。）

6. 個別で選んでも、無作為に持つのと変わらない

指数では「保有日は選べていない」と分かりました。では、個別株の銘柄選びのほうはどうでしょうか。

ここで受動基準線という道具を使います。

552銘柄を無作為に選んで、同じ日数だけ持ったら、それだけで指数を +0.081%/5日 上回ります （全 銘柄×日 212万標本）。これは生存者バイアスによる母集団のドリフトです。 「勝った」と言うには、この線を超えている必要があります。損益分岐は0ではなく、ここです。

定義 押し目の超過 受動基準線との差
リテスト +0.183% +0.102%
半値戻し +0.063% −0.018%
5%押し +0.039% −0.042%
RSI40 +0.009% −0.072%
25日線 −0.018% −0.099%

素の数字だけを見ると、65セル中58セルが指数超過でプラスに見えます。 けれど受動基準線と比べると、超えたのは65セル中わずか13セル。 主結果5セルでは、リテスト1つだけです。

押し目で選んだ銘柄も、同じ母集団を無作為に持つ場合と、ほとんど変わりません。 「良い銘柄を選べていた」と言えるのは、5定義のうち1つだけでした。

7. 唯一の例外を、分解する

リテストだけが受動基準線を超えました。都合よく無視せず、なぜかを分解します。

理由その1: 下げ相場では、そもそも発火しない。 リテストは「250日高値のブレイク」を前提にするため、急落局面では原理的に合図が出ません。 実際、リーマン・震災・Brexit・2018年12月・コロナ・2022年3月・2024年8月の急落イベント6つすべてで、 リテストの合図は0件でした。一方、25日線への押し目はリーマンで3件（平均−3.6%）、 コロナで1件（−5.4%）を踏んでいます。 「押し目を選ぶのが上手い」のではなく、「悪い時期にそもそも存在しない」だけの可能性が高いということです。

理由その2: 生存者バイアスの追い風。 順張り系（高値をブレイクしてから戻りを待つ）は、生存者バイアスが追い風方向に働く形です。 この連載の規約では、こうした「勝った」証拠は最も弱いクラスとして扱います。

理由その3: 指数側では、そもそも確認できない。 指数のリテストは §5 の通り、区間が 0 をまたいでいます（+0.015%・[−0.057%, +0.087%]）。 主結論は指数に置く規約なので、個別側の1件だけをもって「実在する」とは書けません。

コストと先読みでは説明できません（コスト込みでも受動基準線は上回ったまま。 ブレイク水準は前日までの過去情報のみで計算しています）。

→ 理由1と2で、十分に説明がつきます。 「限定的に実在」とは書きません。 ただし理由1は再検証の種として残しておきます—— これはリテストが地合いフィルタを内蔵した形である可能性を示唆していて、 第8回のADX（単位時間あたりの効率が測定できたが由来が未分解）と同じ構造かもしれません。

8. 出てくる疑問を、先に潰しておく

💬 読者の疑問 「RSI40は勝率61%なのに、なぜ0/22なのか」

勝率と期待値は別の量だからです。 RSI40の平均損益は+0.18%どまりで、 かつ市場にいる時間が全体の一部です。何回勝ったかではなく、 買って放置に対して最終的にいくら残ったかで判定しています。

💬 読者の疑問 「34定義の中に、1つくらい効くものがあるのでは」

掃引はしてあります。 65セル×5出口×5コスト=1,625セル（個別）を全部計算しましたが、 買って放置を超えたのは、指数側で1,575セル中5セル相当（各セル22通り中1勝のみ）、 個別側は0でした。protocol の「5%未満」基準を大幅に下回っています。 掃引して出てきた良いセルだけを選んで「これが効く」と書くことは、この連載では禁止しています。 それをやれば、私がこの連載で批判している行為そのものになるからです。

💬 読者の疑問 「25日線と5%押しは、上位3トレードを除いたら負けに転じるのでは」

その通りです。 25日線は上位3トレードを除くと平均損益が −0.13% に、5%押しは −0.27% に転落します。 少数の大当たりに依存していたということです。符号が全期間で安定しているのは半値戻しとリテストだけでした。

9. 効いた日、正反対に動いた日

特異な事例は判定には使いません。 それでも、記録として残しておきます。

  • 5%押しの最大の勝ちは 2013-04-04（異次元緩和の翌日）+13.7%。押し目を拾えたからではなく、 たまたまその翌日に金融政策が変わっただけです。
  • 5%押しは21年中15年で、年ごとの符号が反転しています。「今年効いたか」は、 毎年コインを投げるのに近い頻度です。
  • リテストは急落イベント6つすべてで合図が0件（§7の通り）。

10. 結論

押し目を待って買う、という方法を34通りの具体形で測りました。 個別552銘柄では1トレード単位で65セル全部が勝ち（PF最大1.35）、指数の主結果5定義でも3つは勝ちました （PF最大1.31）。それでも、買って放置には65セル全部が届きませんでした。

第2回からの宿題だった「1トレードの質は良いのに、なぜ負けるのか」に、今回答えが出ました。

押し目が保有していた日は、平均的な日と統計的に区別がつきません。 押し目で選んだ銘柄も、無作為に持つ場合とほとんど変わりません（受動基準線超えは主結果5つ中1つ）。

「市場にいる時間が短くて負けた」という説明は、半分しか正しくありませんでした。 滞在率の低さは、負けの理由ではなく、「選べていないこと」の別の現れだったということです。

唯一受動基準線を超えたリテストも、下げ相場でそもそも発火しないという性質と、 生存者バイアスの追い風でほぼ説明がつきました。

効く時は実在するかもしれません。ただし今回測った34の具体形からは、 それを事前に見分ける手掛かりは見つかりませんでした。 見分けられない以上、手元に残るのは全試行の平均だけで、その平均は買って放置に届きませんでした。

補足: 今回測ったのは、日足で機械的に判定できる34の具体形です。 出来高の細りを伴う押し目、トレンドラインでの反発、裁量による「良い押し目」の見極めは対象外です。 また、なぜ「保有日の質」が平均的な日と区別がつかなくなるのか——その理由そのものは、今回も分かっていません。

この記事で測るのは、1日分（包み足だけは前日との2日分）の形だけです。数字はすべて、事前に決めた定義で固定しています。

0. この記事の立ち位置

ローソク足は、チャートを見る人なら誰でも目にするものです。形に名前がつき、「この形が出たら買い」と語られることも多くあります。

下げている時に出た陽の包み足は、転換のサイン。 ハンマーは底打ち。大陽線は上昇の始まり。 十字線は迷いの表れで、流れが変わる前触れ。

先に、今回の見どころを言っておきます。

1本の足の形には、「良い日を選ぶ力」も、「流れの変わり目を示す力」も、確認できませんでした。 買って放置には、包み足・ハンマー・大陽線のどれも、22通り中1通りも届きませんでした。 大陽線は「上昇の始まり」どころか、1回平均でお金が減っていました。

先に、この記事が言わないこと

ひとつ。 この記事が測ったのは、日足の1本（包み足は2本）の形だけです。三尊や二番底のような複数本の組み合わせ、出来高との併用、分足や場中の足の読み、そして「形を見てから判断する」という裁量の部分は、否定できるだけの検証をしていません。

ふたつ。 形の定義は人によって違います。ここでは代表的な定義を事前に1つ決めて測り、念のため、定義を厳しくした版も測りました（§7）。

みっつ。 個別552銘柄には生存者バイアス（2026年まで生き残った銘柄だけを集めた母集団）があります。この連載の整理では、このバイアスは上がっているものを買う（順張り）に追い風、下げたところを買う（逆張り）に逆風です。包み足とハンマーは逆張り、大陽線は順張りです。個別の結果は相対比較だけに使い、判定は指数だけで行います。

数字の土台は前回までと同じです。対象は1306（TOPIX連動ETF）と個別552銘柄、期間は2005年11月〜2026年7月、コストは往復0.05%（0%でも計算済み）、条件は計算前に文書に固定してあります。

1. 何を測ったか

買いの主張は売買で測りました。

形 買う条件（形が出た日の、翌営業日の始値で買う） 売る
包み足 A 陽の包み足。かつ終値が25日移動平均線より下（下げている最中） 5営業日後の始値
ハンマー B ハンマー。かつ終値が25日移動平均線より下 5営業日後の始値
大陽線 C 大陽線（トレンドの条件はなし） 5営業日後の始値

どの形も「短い期間の転換・初動」を主張しているので、売りは5日後にしました。5日以外も、1・3・10・20日後と「形が出た日の安値を割ったら売る」の合計6通りを、あとで全部測っています（§7）。

十字線は、売買では測っていません。 十字線は「上がる」とも「下がる」とも言っていない足です。主張は「流れが変わる前触れ」ですから、十字線の日の前後で、値動きの向きが逆になっているかを数えました（§6）。

2. 素の成績──包み足とハンマーは、1回ずつはほぼ損益ゼロ

形 回数 勝率 平均損益/回 プロフィットファクター 市場にいた時間
包み足 A 46 54.3% +0.13% 1.10 4.5%
ハンマー B 102 57.8% +0.13% 1.10 10.1%
大陽線 C 17 41.2% −0.45% 0.75 1.7%

（プロフィットファクター＝勝ちの合計÷負けの合計。1を超えれば、手法単体ではお金が増えている）

包み足とハンマーは、勝率が5割台半ばから後半、1回あたり平均+0.13%で、ほとんど損益ゼロです。わずかにプラスですが、往復のコスト0.05%を引いたあとの数字で、1回あたりの余地は小さく見えます。

大陽線は、主張とは逆でした。 「上昇の始まり」と言われる形を買うと、17回の平均は−0.45%。プロフィットファクターは0.75で、手法単体でもお金が減っています。

3. 買って放置と比べる

開始時期を1年ずつずらした22通りで、買って放置と対にして比べました。

結果は、3つの形すべてで0/22でした。

形 買って放置を上回った開始時期 100万円が（22通りの真ん中の値）
包み足 A 0/22 129万円
ハンマー B 0/22 116万円
大陽線 C 0/22 86万円
（買って放置） — 259万円

包み足は129万円、ハンマーは116万円に増えています。 損はしていません。ただ、何もしなかった人は259万円でした。差の130万円と143万円は、損失ではなく「取りこぼし」です。

ただし大陽線だけは違います。100万円が86万円になっています。 こちらは取りこぼしではなく、実際に減っています。

逃げ道は全部ふさいであります。コストを0%にしても0/22。配当を年1.5%・2.0%戻しても0/22。 合図が出ていないあいだのお金を指数（1306）に置いておく形でも、包み足と大陽線が1/22、ハンマーが0/22でした。

ここは、先に認めておくべき点があります。市場にいた時間が4.5%・10.1%・1.7%しかないので、買って放置に届かないのは、測る前から分かっていました。「届かなかった」こと自体は、形の良し悪しを語っていません。

だから、次が本題です。形そのものに情報があるのか。

4. 形に情報はあるのか──3つの物差し

ここが今回の中心です。時間が短いから届かないだけなら、「市場にいた時間あたり」で見れば、形の良さが出るはずです。そこで、形に情報があるかどうかを、3つの物差しで測りました。

物差し①　時間あたりで比べる。 市場にいた時間1単位あたりの増え方で、買って放置と比べ直しました。

形 市場にいた時間 時間あたりで買って放置を上回った開始時期
包み足 A 4.5% 17/22
ハンマー B 10.1% 10/22
大陽線 C 1.7% 0/22

包み足は、時間あたりに直すと22通り中17通りで上回ります。ここは正直に書いておきます。ただ、これは46回の取引（20年で46回）から出た数字で、次の2つの物差しとあわせて読む必要があります。

物差し②　同じ回数だけ、ランダムに買った場合と比べる。 形を見ずに、同じ回数だけ無作為に買う1,000通りと比べました。

形 ランダム1,000通りのうち、これを上回った割合
包み足 A 55.5%
ハンマー B 57.8%
大陽線 C 20.2%

包み足とハンマーは、ほぼランダムの真ん中です。 形を選んで買っても、適当な日に買っても、成績に区別がつきません。大陽線はランダムを下回りました。

物差し③　買っていた日は、ふつうの日より良かったのか。 手法で持っていた日の1日あたりの値動きを、全営業日の平均と比べました。「形が良い日を選べているか」を直接見る物差しです。

形 ふつうの日との差（1日あたり） 統計的な幅（95%）
包み足 A −0.006% −0.189% 〜 +0.174%
ハンマー B −0.009% −0.148% 〜 +0.119%
大陽線 C −0.096% −0.414% 〜 +0.200%

3つとも、幅が0をまたいでいます。 主結果と頑健性の確認をあわせた10通りでも、すべて0をまたぎました。形が出た翌日から持った日は、ふつうの日と区別がつきません。

物差し②と③で見ると、足の形が「良い日」を選べている証拠は見つかりませんでした。 物差し①の包み足17/22は、この2つとあわせて読むと、形の力を示すものとは言えません。

5. 「下げた後に買う」が効いていたのか

包み足もハンマーも、プロフィットファクターは1.10でした。この1.10は、何から来ていたのでしょうか。

この2つの形には、「25日線より下」（下げている最中）という条件を付けていました。この条件を外す（下げていなくても、形が出たら買う）と、どうなるか。

25日線の下 75日線の下 条件なし
包み足 1.10（46回） 1.11（46回） 0.94（127回）
ハンマー 1.10（102回） 1.04（89回） 0.95（232回）

条件を外すと、2つともプロフィットファクターが1を割りました（お金が減る側）。

つまり、PF1.10は形が出たからではなく、下げている最中に買っているから出ていた可能性があります。連載の第14回（移動平均乖離率）で見た「下げたら戻る」と、同じ性質です。

ただし、「下げている最中に、形なしで買った場合」は今回測っていません。したがって、「形に意味がない」と言い切れるわけではなく、形の効果と、下げた後に買う効果を、この検証では切り分けられていないというのが正確なところです。

もう一つ、ここまでの数字を支えていたものがあります。上位3回の取引を除くと、包み足はPF0.71、ハンマーは0.93、大陽線は0.28と、3つとも1を割りました。数回の大きな当たりで成り立っていたことになります。

6. 十字線は「迷い」なのか、「転換の前触れ」なのか

十字線は、始値と終値がほぼ同じ足です。「買いも売りも決め手がない迷いの表れで、その後に流れが変わりやすい」と言われます。

十字線が出たら、そこで相場の向きが変わる。 とくに、大きく動いた後の十字線は要注意。

これは売買の主張ではなく、相場の性質についての主張です。だから売買ではなく、直接測りました。

十字線が出た日の前後（3・5・10営業日）で、値動きの向きが逆になった割合を数えます。比べる相手は、十字線ではない日のうち、直前の値動きの大きさが同じくらいの日（1,000回くじ引き）。大きく動いた後は、それだけで反転しやすくなるので、そこをそろえておく必要があるからです。

指数で十字線が出た日は、約480回ありました。

十字線の前後 向きが逆になった割合 ふつうの日（真ん中） ふつうの日の95%の上端
3営業日 49.7% 50.7% 54.1%
5営業日 49.4% 49.8% 53.7%
10営業日 46.7% 49.7% 53.3%

3つとも、ふつうの日の幅の中でした。 しかも3つとも、真ん中より下です。十字線の後のほうが、むしろ反転しにくい向きでした。

「迷い」の度合いをもう一段厳しくした版（実体が値幅の5%以下）でも測りました。

十字線の前後 向きが逆になった割合 ふつうの日（真ん中）
3営業日 45.6%（248回） 50.8%
5営業日 49.8%（247回） 50.2%
10営業日 43.1%（253回） 49.8%

迷いが強いほど、反転しにくい向きに見えます。10日では、ふつうの日の幅の下にまで出ました。

ただし、これは念のための確認で、主結論に据えたのは最初の定義（10%以下）です。回数も250回ほどで、「十字線の後は流れが続く」と言い切る材料にはなりません。確かに言えるのは、転換の前触れとは言えなかったところまでです。

個別552銘柄でも測りました。向きが逆になった割合は50.3〜50.6%で、ふつうの日と同じ数字でした（コインを投げた場合と区別がつきません）。

十字線は、「迷い」を表しているのかもしれません。ただ、その迷いの後に流れが変わる、という性質は、見つかりませんでした。

7. 出てくる疑問を、先に潰しておく

💬 読者の疑問 「5日持つのは短すぎるのでは。もっと持てば効くのでは」

売りの日を6通り（1・3・5・10・20日後と、形が出た日の安値を割った日）、形の設定を9通り（包み足・ハンマー・大陽線それぞれ3通り）、コストを2通り（0%と0.05%）、すべての組み合わせを測りました。買って放置との対戦は108通り。その中で、22通りの過半で買って放置を上回ったものは、ひとつもありません（1つでも上回れたのは2通りだけで、最もよいものでも4/22。どちらも条件なしのハンマーを20日持った形でした）。

💬 読者の疑問 「形の定義が人によって違う。もっと厳密に絞れば効くのでは」

定義を厳しくした2版も測りました。ハンマー（下ヒゲが実体の3倍以上）は57回でPF1.23ですが、買って放置には0/22。包み足（前日の高値・安値まで包む）は24回でPF0.67と、むしろ悪化しました（お金が減る側）。定義を厳しくしても、良くなる方向には動きませんでした。

💬 読者の疑問 「形は他の条件と組み合わせてこそ。単独で測るのはフェアでないのでは」

その通りで、今回測ったのは単独の形（と「25日線の下」という最小限の条件）だけです。組み合わせは、増やすほど「後から当たる組み合わせを拾える」余地が広がります。この連載は当たりを探す作業ではないので、組み合わせを広げる検証はしていません。組み合わせの評価は、この記事の外です。

💬 読者の疑問 「個別銘柄で使う人が多いのでは」

個別552銘柄でも、3つの形すべてで買って放置に0/17でした（個別は開始時期17通り）。

ここは、ひとつ正直に書いておきます。個別では、手法で持っていた日が、ふつうの日よりわずかに良く見える場合がありました（コスト0%で1日あたり+0.07〜0.10%程度）。ただ、往復0.05%のコストを入れると、幅が0をまたぎます。ランダム比較でも、個別ではハンマーが85%の位置にいて、指数ほど「区別がつかない」わけではありませんでした。

大陽線は順張りで、個別の母集団は追い風を受けています。ハンマーは逆張りで逆風側ですから、ここは弱い手がかりではあります。ただ、買って放置に勝てたわけではなく、コストを入れると差が消えている点は、指数と同じです。

8. 効いた時、そうでなかった時

平均では届きません。しかし、常に効かないわけではありません。

包み足 A のいちばん大きな勝ちは、2020年3月18日に買って、26日に売った+9.7%でした。 コロナ・ショックの大底の、陽の包み足です。ハンマー B のいちばん大きな勝ちは、2011年3月16日に買って24日に売った+9.4%。東日本大震災の暴落直後のハンマーでした。この2回だけを見れば、「底打ちの形」は見事に当たっています。

一方、ハンマー B のいちばん大きな負けは、2008年10月2日に買って9日に売った−19.5%でした。 リーマン・ショックの渦中に出た、これも定義どおりのハンマーです。「底打ち」の形から、1週間で2割近く下げました。

左がリーマン期のハンマー、右がコロナ底の包み足です。どちらも「下げ止まりの形」が出ています。 結果は、−19.5%と+9.7%に分かれました。

勝ちも負けも、暴落期に集中していました。形そのものではなく、その時の相場の局面が、損益を決めていたように見えます。（※これらは、最も大きな勝ち負けを事後に取り出したもので、判定には使っていません。）

時期でも、食い違いがありました。

前半（2016年2月までに買った分） 後半（2016年3月以降に買った分）
包み足 A プロフィットファクター 0.50（27回） 6.88（19回）
ハンマー B 0.85（56回） 1.67（46回）
大陽線 C 1.84（10回） 0.13（7回）

包み足とハンマーは前半に弱く、後半に強い。大陽線は逆でした。年ごとに見ても、損益の符号が全期間の平均と逆になった年が、包み足で18年中7年、ハンマーで21年中10年、大陽線で14年中6年ありました。

2016年の初めに包み足を使っていた人は、「これは当てにならない」と感じていたはずです。 2026年の今使っている人は、「よく効く」と感じているかもしれません。 どちらの体感も嘘ではありません。ただ、次の10年がどちらになるかは、買う時点では分かりませんでした。

9. 結論

包み足とハンマーは、手法単体ではお金を増やしていました（100万円が129万円・116万円）。ただ、何もしなければ259万円でした。大陽線は、「上昇の始まり」の主張と逆に、100万円が86万円に減っていました。

そして、買って放置に届かなかった理由は、市場にいる時間が短いからだけではありませんでした。

  • ランダムに買った場合と区別がつかない（包み足55.5%・ハンマー57.8%）
  • 持っていた日は、ふつうの日と区別がつかない（3つとも幅が0をまたぐ）
  • PF1.10は、形ではなく「下げた後に買う」条件に支えられていた可能性がある（条件を外すとPF1を割る）
  • 十字線の後に、流れが変わる性質は見つからなかった（むしろ反転しにくい向き）

効く時は実在します。コロナ底の包み足は+9.7%、震災後のハンマーは+9.4%でした。 ただし、同じ「底打ちの形」が、リーマン期には−19.5%でした。どちらの局面なのかは、形が出た時点では分かりません。 見分けられない以上、残るのは平均だけです。そしてその平均は、何もしない場合に届きませんでした。

ローソク足の形には、名前がついていて、その名前が「ここで何かが変わる」という物語を運んでくれます。ただ、その物語を、1本の足の形が支えていたかというと、今回の測定では支えきれていませんでした。形を見て「ここだ」と感じた経験は嘘ではありません。ただ、その感覚が、形そのものから来ていたのか、その日の相場全体の空気から来ていたのかは、足1本からは切り分けられませんでした。

補足: 010 は2026年10月に計算しました。個別552銘柄の絶対成績は、生存者バイアスのため公開していません。十字線の「5%以下」版は、主結論とは別の念のための確認です。

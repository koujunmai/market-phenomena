「MACDなら早い」は本当か──速さは効いた。それでも買って放置には届かない

0. この記事の立ち位置

第1回で移動平均のゴールデンクロスを調べたとき、違和感があったのは次のことです。

移動平均は遅いから。 クロスが出た頃にはもう上げ終わってる。 MACD を使えばいい。あれは移動平均より反応が早いはず。

これは筋の通った疑問です。実際 MACD は、そういう不満から生まれた指標です。 2本の移動平均の差を見ることで、移動平均そのものより早く向きの変化をつかもうとする。 入門書でも「移動平均の弱点を補う指標」として紹介されます。

そこで今回は、この疑問をそのまま検証しました。そして今回は、これまでの3回とは結果の見え方が違います。

先に結論の形だけ言っておきます。

「MACD のほうが早い」は、データの上でも正しかった。 1回あたりの成績は、これまでの4つの現象の中でいちばん安定していた。 暴落での落ち込みも、買って放置よりはっきり浅かった。 それでも、手元に残った金額は買って放置に届かなかった（0/22）。

これまでの3回は「勝率が低い」「1トレードは良いが取引が少なすぎる」など、 どこかに分かりやすい弱点がありました。今回はそれがありません。 弱点らしい弱点がないのに届かない、というのが今回の見どころです。

使う数字の土台は前回までと同じです（詳しくは第0回・第1回で扱っています）。

  • 対象は 1306（TOPIX連動ETF） と、国内の中〜大型株 552銘柄。期間は 2005-11 〜 2026-07。
  • 個別552銘柄には生存者バイアスがあるので、絶対的な成績は出さず、比べ方（相対比較）だけに使います。 主な結論は、バイアスのない指数（1306）で出します。
  • 比較の基準は 「買って放置」。最初に一度だけ買って、あとは何もせず持ち続けるだけ。 チャートも見ないし、売買の判断もしません。積立（毎月コツコツ買う）とは別物です。

先に、言葉の意味を2つだけ確認させてください。

  1. この記事の数字は、ことわりのない限りすべて「指数（1306）」のものです。 個別株ではありません。
  2. これから「届かない」と書くのは、"お金が減る"という意味ではありません。 今回の手法は、お金はちゃんと増えます。問題は、同じ期間ただ1306を買って放置していたほうが、もっと増えていたこと。 ここでの「負け」は、損失ではなく"取りこぼし"です。これは記事の途中で金額で確かめます。

1. 「MACD のゴールデンクロス」を、計算できる形にする

MACD は、短い期間の移動平均から、長い期間の移動平均を引いた値です。 2本の線が開けば数字が大きくなり、近づけば小さくなる。だから「差の変化」を通じて、 移動平均そのものより一歩早く向きの変化が出ます。

チャートには2本の線が出ます。

  • MACD線：上で説明した「差」そのもの
  • シグナル線：MACD線をさらに平らにならしたもの

そして定番の読み方はこうです。

MACD線がシグナル線を下から上に抜けたら買い（ゴールデンクロス）、上から下に抜けたら売り（デッドクロス）。

数値は (12, 26, 9) という組み合わせが事実上の標準で、どのチャートソフトでも初期値になっています。 今回はこれを主役に据えました。

💬 読者の疑問 「MACD には『ゼロラインより下で出たクロスが本物だ』とか、 『MACD がゼロを超えたら買い』とか、いろんな流儀がありますよね。それは？」

それも全部やりました。 ここが今回の工夫です。買い方を3通り用意しています。

買い方 誰が言う形か
A 素のGC MACD線がシグナル線を上抜けた、その翌朝に買う いちばん素直な、教科書どおりの形
B ゼロライン下でのGC 上抜けがゼロラインより下で起きたときだけ買う 「安いところで出たクロスが本物。高いところのクロスはダマシ」という定番の絞り込み
C ゼロライン上抜け MACD線そのものがゼロを上抜けた翌朝に買う 「ゼロを超えたら上昇転換」という、別系統の定番

Aだけを検証すると、必ず「それは下手なやり方だ」と言われます。 なので最初から3つとも回しました。どれも計算の前に条件を登録して凍結してあります。

出口は、それぞれの言い分どおりです。A と B は「デッドクロスが出たら」、C は「ゼロラインを割ったら」。 （あわせて「1日で降りる」「5日で降りる」など、機械的に日数で降りる形も全部試しています。）

数値の組み合わせも 12・26 だけではなく、短期側 5〜24 × 長期側 13〜52 の 21通りを掃引しました。 全部で 21通り × 3つの形 × 出口7通り × 手数料5水準 = 2,205通りを計算しています。

空売り（デッドクロスで売り建てる）は今回扱っていません。これは正直に、検証していない範囲として書いておきます。

2. まず、単体の成績を見てみる──今回は、素直に良い

指数（1306）で回した結果です（往復5bpsの手数料を引いています）。

買い方 取引数 勝率 1回あたり平均 PF
A 素のGC 205 39.0% +0.15% 1.12
B ゼロライン下でのGC 111 41.4% +0.47% 1.30
C ゼロライン上抜け 83 37.3% +0.70% 1.35

3つとも PF が 1 を超えました。 つまり、どの形でもお金は増えています。 第2回の押し目買い（SMA25 で PF 0.81）のように、単体で負けている形はひとつもありません。

そして「MACD は早い」という主張は、取引数にはっきり出ています。 20年で 205回・111回・83回。第3回の RSI 逆張りが 20年で16回しか売買しなかったのと比べると、 MACD は桁違いに頻繁にシグナルを出します。「反応が早い」は、体感どおりでした。

💬 読者の疑問 「じゃあ今回は勝ちなんじゃないですか。PF 1.35 なら十分では」

単体で見れば、そのとおりです。 ここは正直に認めます。 これまでの3回のように「勝率が3割を切る」「1トレードが赤字」といった分かりやすい弱点がありません。

──ですが、比較する相手を置くと、また景色が変わります。

3. 「買って放置」と比べる──PF 1.35 でも、0勝

これまでと同じ土俵です。開始した年を1年ずつずらして 22通り、 それぞれ「1306で MACD を売買した場合」と「1306を買って放置した場合」の、どちらが期末に多く残ったかを数えます。

買い方 MACD の中央値 買って放置の中央値 MACD が勝った開始日
A 素のGC +19.3% +159.1% 0 / 22
B ゼロライン下でのGC +50.0% +159.1% 0 / 22
C ゼロライン上抜け +31.3% +159.1% 0 / 22

22通りのどこから始めても、一度も上回りませんでした。

金額で見ます。2005年11月に100万円を投じて、そのまま2026年7月まで置いた場合です。

  • 買って放置 → 275万円
  • MACD A（素のGC）→ 113万円
  • MACD B（ゼロライン下でのGC）→ 147万円
  • MACD C（ゼロライン上抜け）→ 147万円

ここで大事なのは、MACD でも、お金は減っていないということです。100万円は113〜147万円に、ちゃんと増えています。 損をしたわけではありません。 ただ、同じ期間、何もせずただ1306を持っていれば275万円になっていた。 その差の 約128〜162万円は、"損失"ではなく"取りこぼし" です。

手法に意味があるかどうかは、「勝ったかどうか」では決まりません。 何もしない人に勝てたかどうかで決まります。 PF が 1.35 でも、買って放置した人に届いていないなら、 その手法がやったことは「手間をかけて成績を下げた」ということです。

そして今回いちばん大事なのは、下段のドローダウンの図です。

買って放置 A 素のGC B ゼロライン下GC C ゼロライン上抜け
いちばん深く沈んだ時 -61.3% -38.7% -35.2% -30.5%

MACD は、はっきり逃げられていました。 買って放置がリーマンショックで6割沈んだのに対し、 MACD は3〜4割の落ち込みで済んでいます。これは手法の実在する利点です。隠しません。

そして、上段の図をもう一度見てください。

2013年ごろまで、MACD の線は買って放置よりも上にあります。 リーマンショックで買って放置が半値まで沈んでいる間、MACD は現金に逃げていたので、 7年近くにわたって「MACD のほうが勝っている」状態が続いていました。

これは印象論ではなく、日数で数えられます（2005年11月に始めた1本の経路で）。

買って放置を上回っていた日数 最後に上回っていた日
A 素のGC 1,839 / 5,058日（36%） 2020-03-16
B ゼロライン下でのGC 2,181 / 5,058日（43%） 2020-10-30
C ゼロライン上抜け 2,590 / 5,058日（51%） 2022-03-14

C にいたっては、20年のうち半分以上の日で買って放置に勝っていました。 しかも決定的に置いていかれたのは、2022年3月です。

ここは、この連載でいちばん強調しておきたいところです。

「MACD で勝てている」という体感は、嘘ではありません。 実際、20年のうちの過半で、その人は本当に勝っていました。

少なくともこの1本の経路（2005年11月に始めた場合）を2021年時点で切り取っていれば、 「MACD は買って放置に勝っている」というグラフが描けました。 手法が負けるのは、いつも最後にまとめてです。 上げ相場が来たときに、 市場にいない時間のぶんだけ一気に離される。それまでは、ずっと勝っているように見えます。

そして、これがこの連載で「開始日を22通りずらして数える」ことにこだわっている理由でもあります。 期間の切り取り方ひとつで、同じ手法が勝ちにも負けにもなるからです。

つまり今回の結果は、こういう形をしています。

お金は増えた。下げからも逃げられた。20年の半分は勝ってさえいた。 それでも、最後に手元に残った金額は、何もしなかった人に届かなかった。

4. 出てくる疑問を、先に一緒に潰しておく

「(12,26,9) が悪い。パラメータを変えれば」

短期側 5〜24 × 長期側 13〜52 の 21通りすべてを計算しています。

3つの形すべてで、21通り全部が 0/22 でした。 「たまたま選んだ数値が悪かった」という逃げ道はありません。

「ゼロラインより下のクロスだけ拾えばいいんだ」

これが B です。そして部分的には、この助言は正しい。 PF は 1.12 → 1.30 に、1回あたりの平均も +0.15% → +0.47% に改善します。 「安いところのクロスが本物」という感覚は、データの上でも当たっていました。

ところが、買って放置に勝った開始日は 0/22 のまま動きません。理由は次の節で扱います。

これは第1回で見た「パーフェクトオーダー」とまったく同じ形です。 条件を厳しくすると、1回あたりの質は上がるのに、勝敗は変わらない。

「デッドクロスまで待つから遅いんだ。出口を変えれば」

出口は7通り試しました（デッドクロス／ゼロライン割れ／1・3・5・10・20日で機械的に降りる）。 2,205通りの組み合わせ全体で、買って放置に勝った開始日が過半を超えたものは、ひとつもありません。

「シグナルが出ていない間は現金だろう。市場にいる時間が違う」

この指摘は正当です。 なので、シグナルが出ていない期間の資金を 1306 に置いた場合でも計算しました。 「MACD ＋ 余ったお金は指数」対「全部指数」なら、市場にいる時間の差が消えます。

結果は 3つとも 0/22（中央値 +145.7% / +153.2% / +153.9% 対 +159.1%）。 市場にいる時間を揃えても、売買した分だけ下回ります。

「手数料が厳しすぎるのでは」「配当を入れれば放置が有利なだけでは」

手数料 0（無料） でも 0/22 です。 配当については、今回の計算は配当を含めていません。含めれば、ずっと持ち続けている買って放置のほうが 有利になります。つまり本稿は買って放置を過小評価した、手法側に甘い比較です。それでも届きませんでした。

「同じ回数だけ、ランダムに買ったら？」

MACD と同じ回数・同じ保有期間で、日付だけランダムに選んで買う試行を1,000回やりました。

  • 指数では、MACD の成績はランダムの分布の 32.9 / 58.8 / 40.5 パーセンタイル。ほぼ真ん中で、区別がつきません。
  • 個別552銘柄では 4.2 / 1.6 / 0.4 パーセンタイル。つまりランダムに買ったほうが良かった側です。

「個別株ならどうなんですか」

個別552銘柄では、1回あたりの成績はもっと良く見えます（PF 1.30〜1.50）。 それでも買って放置に勝った開始日は 0/17 でした。

しかもここは重要な点です。個別552銘柄のデータは、上がり続けた銘柄に偏っています（第0回の生存者バイアス）。 偏りは「流れに乗る」やり方に有利に働くので、MACD にとっては追い風です。 その追い風の中で 0/17 だったのなら、この結果はバイアスのせいにはできません。

5. なぜ勝てないのか──市場にいなかった時間

答えは、今回はとてもはっきりしています。

横軸が「その手法が実際に株を持っていた時間の割合」、縦軸が「手元に残ったリターン」です。 右上の星が買って放置（ずっと持っている＝100%）。

これまで見てきた現象が、全部その左下に並びます。

MACD の市場滞在率は A 51.9% / B 33.0% / C 64.4%。 つまり期間の半分前後は、現金で待っていたことになります。 その間に市場が上げても、その上げは手元に入りません。

そして、この図がいちばんよく説明するのが B（ゼロライン下でのGC） です。 Bは1回あたりの質を上げました（PF 1.30）。しかしそのために滞在率が 51.9% → 33.0% に落ちています。 「良いクロスだけを選ぶ」とは、「株を持っていない時間を増やす」ことでもある。 質の改善と、市場にいない時間の増加が打ち消し合って、結果は動きませんでした。

第1回のパーフェクトオーダーが 62%→46%、第2回の押し目買いが 28% まで落ちたのと、まったく同じ構造です。 この連載で、条件を厳しくして成績が改善した例は、いまのところ一つもありません。

数字でも確認できます。貢献の大きかった上位3回の取引を除くと、 PF 1.12 だった A は 0.95、PF 1.35 だった C は 0.84 まで落ちて1を割り込みます。 20年ぶんの見かけの成績は、数回の大当たりに支えられていました。

6. 「でも、効いた時は本当にあったよね」──ここが核心

ここまで読んで、「MACD のクロスで大きく取れたことがある」と思った方へ。その記憶は正しいです。

最大の勝ちは 2012年11月です。11月19日に MACD がシグナル線を上抜け、 ルールどおり翌営業日＝11月20日の寄り付きで買っています。そこから40営業日持って +15.8%。

この日は、MACD がシグナル線とゼロラインを同時に上抜けた日でした。 だから A（素のGC）と C（ゼロライン上抜け）の最大の勝ちは、まったく同じ1回の取引です。

そして、ここが少し不気味なところです。

第1回のクロス（11月21日・11月15日買い）、第1回の絞り込み（11月21日買い）、 第2回の押し目買い（11月19日買い・3つの形すべて）、そして今回の MACD（11月20日買い）。 別々の指標で調べたはずの「最大の勝ち」が、2012年11月15日〜21日の1週間に集まっています。

もちろん例外もあります（第1回の(50,200)は2025年、第3回の RSI 逆張りは2024年8月が最大の勝ちでした）。 それでも、これだけ違う指標の「いちばん儲かった1回」が同じ週に固まるのは偶然ではありません。

これは手法の優秀さではありません。アベノミクス相場の入り口で、たまたま全部が同じ方向を向いたというだけです。 どの指標を使っていても、あの数日に買えていれば大きく取れました。逆に言えば、 この連載で調べた手法の「見かけの成績」は、かなりの部分が同じ数日から来ています。

年別に見ると、こうなります。

21年のうち9年がマイナスです。最悪は2008年の -33.2%、最良は2012年の +24.4%。 そして、この2つはまったく同じ判断ルールの結果です。

もう一つ、下げ局面の記録を出しておきます。「早い」ことは、下げでは裏目に出ます。

局面 MACD（素のGC）の成績
2008年9〜11月（リーマン） 4回買って、4回とも負け（-5.8% / -5.0% / -13.7% / -3.3%）
2011年3月（震災） 1回・-2.4%
2016年6月（Brexit） 2回・-4.2% / -3.0%
2020年3月（コロナ） 3月26日に買って +12.8%（大底の直後を拾えた）

リーマンショックのさなかには、4回シグナルが出て、4回とも負けました。 下げ相場では2本の線が何度も交差するので、「早い」指標ほど何度も引っかかります。 一方でコロナの大底直後は、きれいに拾えています。

問題は、それが「効く時」かどうかを事前には分からなかったことです。 2008年10月30日のクロスと、2012年11月19日のクロスは、その時点では見分けがつきません。 チャート上ではどちらも「MACD がシグナル線を上抜けた」というだけの、同じ形をしています。

「見分けられない」は、想像ではなく実測です

「効く時を事前に選べばいい」という話は、たいてい言いっぱなしで終わります。 けれどこのリポジトリには、「効く時と効かない時を事前に振り分けようとして、失敗した記録」が積み上がっています （相場局面の予測を独立に6回／カレンダー条件／VIX／月末条件──いずれも不発）。

「見分けられないと思います」ではなく、「見分けようとして、これだけ失敗しました」と言えます。

正直に書いておくこと

2,205通りを全部計算したので、いちばん見栄えのする組み合わせも分かっています。 短期5・長期13で、ゼロライン下のクロスで買い、ゼロライン割れで降りる形。 これは PF 1.74、買って放置に勝った開始日は 22回中10回まで行きます。

隠すとフェアではないので書きますが、2つ添えます。 ひとつは、それでも半分（11回）に届いていないこと。 もうひとつは、勝った10回が2006〜2008年と2014〜2020年に固まっていて、 2009〜2013年と2021年以降には1回もないこと。

そして何より、これは2,205通りを計算し終わってから選んだ組み合わせです。 2005年の時点でこれを選べた人はいません。後から一番良かったものを指さすのは、 この連載が調べている「効いた事例だけが残る」構造そのものです。

7. まとめ──「弱点がない」ことが、いちばん厄介だった

MACD のゴールデンクロスは、次の形に落ち着きました。

「移動平均より早い」は本当だった（20年で205回・RSI逆張りの13倍の頻度）。 1回あたりの成績も、3つの形すべてで PF が1を超えた（1.12 / 1.30 / 1.35）。 暴落での落ち込みも、買って放置よりはっきり浅かった（-30〜-39% 対 -61.3%）。 20年のうち36〜51%の日は、買って放置に本当に勝っていた。 「ゼロライン下のクロスが本物」という助言も、確かに1回あたりの質を上げた。 効いた瞬間も、確かに実在した（2012年11月・+15.8%）。 けれど、市場にいなかった時間のぶんだけ上げを取りこぼし、 手元に残った資産は、ただ買って放置していた場合に届かなかった（0/22）。

第1回の「乗る・降りる」、第2回の「安く拾う」、第3回の「売られすぎを買う」に続いて、 今回の「指標を速いものに替える」でも、結論は同じでした。

乗っても、絞っても、押し目を待っても、逆張りしても、速くしても、買って放置には届かなかった。

今回とくに気をつけたいのは、「弱点が見当たらない」という手応えです。 第2回は「PFが高いのに勝てない」、第3回は「10回中8回勝っているのに勝てない」でした。 どちらも、どこかに引っかかりがありました。

今回は違います。お金は増える。下げからは逃げられる。取引回数も十分ある。 しかも20年の半分近くは、実際に買って放置に勝っている。 文句のつけどころが、ほとんどありません。それでも、最後には届かない。

理由は、手法の出来の悪さではなく、構造のほうにありました。 売買のルールは「持つ時間」を必ず削ります。削られた時間の中で市場が上げれば、その上げは手に入りません。 上げ相場に居続けることが、いちばん強い。売買が上手いかどうかとは別の話です。

この記事が相手にしているのは、MACD という指標そのものではありません。 「効いた事例だけが記憶と発信に残る」という構造のほうです。 2012年11月に拾えた+15.8%は記憶に残り、リーマンショックの4連敗は、たいてい語られません。 そして「MACD は早い」という主張自体は本当なので、なおさら反証されにくい。 その非対称を、自分の手元のデータで一度ほどいてみた、というのがこの記事でした。
